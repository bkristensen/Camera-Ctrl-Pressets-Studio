## Proposer un changement

1. Lisez [Contributing](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/blob/main/Source/CONTRIBUTING.md) et recherchez un problème ou une demande d'extraction connexe.
2. Forkez le référentiel si vous n'avez pas d'accès en écriture. Créez une branche à partir de la branche `main` du projet.
3. Apportez une modification ciblée, vérifiez-la et validez-la avec une brève description. Poussez la branche jusqu'à votre fourchette.
4. Dans l'onglet **Pull request** du projet, ouvrez une pull request ciblant `main`. Expliquez ce qui a changé, comment vous l'avez testé et associez tout problème connexe.
5. Suivez les vérifications et l'examen. Envoyez les corrections vers la même branche afin qu'elles apparaissent dans la demande d'extraction existante.

Pour les modifications de traduction, voir [Traduisez l'application](TRANSLATIONS.md).
