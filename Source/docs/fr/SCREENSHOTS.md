## Actualiser les images du guide

À partir du dossier de solution, exécutez `./scripts/capture-docs.ps1` sous Windows. Il utilise des exemples de données et écrit les fichiers PNG dans `docs/images/screenshots/<version>/<language>/`. Il capture toutes les vues du tableau pour l'anglais, le danois et l'allemand, ainsi que six vues pour chacune des neuf autres langues. Le script capture également le guide rapide danois annoté [](../images/screenshots/1.0.1/da/quick-guide.png).

Utilisez une mise à l'échelle d'affichage de 100 % et une zone de travail d'au moins 1 440 × 800 pour les fenêtres complètes. Examinez les captures avant de mettre à jour le README et les guides. Conservez les dossiers et fichiers de capture d'écran antérieurs dans leurs chemins d'origine afin que les liens vers les anciennes versions fonctionnent toujours.
