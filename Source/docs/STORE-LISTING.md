# Store listing draft — review before submission

## Product name
Cam Pressets Studio (subject to name reservation).

## Short description
Save camera positions and switch between repeatable views with precise controls.

## Description
Cam Pressets Studio gives compatible Windows camera drivers a compact control
panel for pan, tilt and zoom. Save named positions, recall them with adjustable
transitions, and organise settings in profiles. A dual-ring wheel offers normal
and fast steps; a collapsible settings panel keeps the main view simple.

Use it alongside your video application for presentations, demonstrations,
recording or conferencing. Studio does not capture or transmit video or audio.
Available controls and smoothness depend on your camera and driver.

The project owner's reference setup is Logitech BRIO with Zoom. Other devices
and applications are not yet verified. The default startup safeguard requires Zoom
to be running and asks you to confirm that its meeting is ready before camera access.
For other workflows, this Zoom-specific safeguard must be explicitly disabled.

English, Danish and German interface. Open source under MIT. No preview, virtual camera,
screen-sharing automation or multi-source video composition is included.
