# Camera Control Studio auf GitHub

*Geschrieben für Camera Control Studio 1.0.1.*

Öffnen Sie das Projekt [ auf GitHub](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio), um Code, Anleitungen, Veröffentlichungen und öffentliche Berichte zu lesen. Melden Sie sich an, um eine Änderung zu posten oder vorzuschlagen.

<https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio>

| Bereich | Benutze es für |
| --- | --- |
| Code | Durchsuchen Sie den Quellcode, die README-Datei und die Beitragsanweisungen. |
| Veröffentlichungen | Laden Sie ein veröffentlichtes Installationsprogramm oder ein tragbares ZIP von **Assets** herunter und lesen Sie die Versionshinweise. |
| Probleme | Suchen, melden und verfolgen Sie Fehler oder konkrete Funktionswünsche. Siehe [Ein Problem melden oder verfolgen](ISSUES.md). |
| Diskussionen | Stellen Sie Fragen zur Verwendung oder diskutieren Sie Ideen, die noch Gestalt annehmen. |
| Pull Requests | Überprüfen Sie vorgeschlagene Änderungen und verfolgen Sie die Diskussion und Überprüfungen. |

## Schlagen Sie eine Änderung vor

1. Lesen Sie [Contributing](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/blob/main/Source/CONTRIBUTING.md) und suchen Sie nach einem verwandten Problem oder Pull-Request.
2. Forken Sie das Repository, wenn Sie keinen Schreibzugriff haben. Erstellen Sie einen Zweig aus dem Zweig `main` des Projekts.
3. Nehmen Sie eine gezielte Änderung vor, überprüfen Sie sie und committen Sie sie mit einer kurzen Beschreibung. Pushen Sie den Branch in Ihren Fork.
4. Öffnen Sie auf der Registerkarte **Pull request** des Projekts einen Pull Request für `main`. Erklären Sie, was sich geändert hat, wie Sie es getestet haben, und verknüpfen Sie alle damit zusammenhängenden Probleme.
5. Befolgen Sie die Kontrollen und überprüfen Sie. Push-Korrekturen in denselben Zweig übertragen, damit sie im vorhandenen Pull-Request angezeigt werden.

Informationen zu Übersetzungsänderungen finden Sie unter [App übersetzen](TRANSLATIONS.md).
