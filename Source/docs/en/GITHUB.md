# Camera Control Studio on GitHub

Open the [project on GitHub](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio). You can read the code, guides, releases and public reports without editing the project. Sign in to post or propose a change.

| Area | Use it for |
| --- | --- |
| Code | Browse the source, README and contribution instructions. |
| Releases | Download a published installer or portable ZIP from **Assets** and read the release notes. |
| Issues | Search, report and follow bugs or concrete feature requests. See [Report or follow an issue](ISSUES.md). |
| Discussions | Ask usage questions or discuss ideas that are still taking shape. |
| Pull requests | Review proposed changes and follow the discussion and checks. |

## Propose a change

1. Read [Contributing](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/blob/main/Source/CONTRIBUTING.md) and look for a related issue or pull request.
2. Fork the repository if you lack write access. Create a branch from the project's `main` branch.
3. Make a focused change, verify it, and commit it with a short description. Push the branch to your fork.
4. In the project's **Pull requests** tab, open a pull request targeting `main`. Explain what changed, how you tested it, and link any related issue.
5. Follow the checks and review. Push corrections to the same branch so they appear in the existing pull request.

For translation changes, see [Translate the app](TRANSLATIONS.md).
