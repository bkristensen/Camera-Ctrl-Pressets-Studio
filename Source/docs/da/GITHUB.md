## Foreslå en ændring

1. Læs projektets [retningslinjer for bidrag](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/blob/main/Source/CONTRIBUTING.md), og søg efter en relateret sag eller pull request.
2. Opret en fork, hvis du ikke har skriveadgang. Lav en branch fra projektets `main`.
3. Lav og afprøv ændringen. Commit den med en kort beskrivelse, og push din branch.
4. Åbn en pull request mod projektets `main`. Forklar ændringen og din test, og link til en eventuel sag.
5. Følg kontrollerne og gennemgangen. Push rettelser til samme branch, så de vises i den samme pull request.

Se også [Oversæt programmet](TRANSLATIONS.md).
