# Camera Control Studio dan GitHub

*Ditulis untuk Camera Control Studio 1.1.0.*

Buka proyek [ di GitHub](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio) untuk membaca kode, panduan, rilis, dan laporan publik. Masuk untuk memposting atau mengusulkan perubahan.

<https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio>

| Daerah | Gunakan untuk |
| --- | --- |
| Kode | Jelajahi sumber, README dan instruksi kontribusi. |
| Rilis | Unduh penginstal yang diterbitkan atau ZIP portabel dari **Assets** dan baca catatan rilis. |
| Masalah | Cari, laporkan, dan ikuti bug atau permintaan fitur nyata. Lihat [Laporkan atau ikuti masalah](ISSUES.md). |
| Diskusi | Ajukan pertanyaan penggunaan atau diskusikan ide yang masih terbentuk. |
| Tarik permintaan | Tinjau perubahan yang diusulkan dan ikuti diskusi dan pemeriksaan. |

## Usulkan perubahan

1. Baca [Contributing](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/blob/main/Source/CONTRIBUTING.md) dan cari masalah terkait atau permintaan penarikan.
2. Fork repositori jika Anda tidak memiliki akses tulis. Buat cabang dari cabang `main` proyek.
3. Buat perubahan terfokus, verifikasi, dan terapkan dengan deskripsi singkat. Dorong dahan ke garpu Anda.
4. Di tab **Pull request** proyek, buka permintaan pull yang menargetkan `main`. Jelaskan apa yang berubah, bagaimana Anda mengujinya, dan tautkan masalah terkait apa pun.
5. Ikuti pemeriksaan dan reviewnya. Dorong koreksi ke cabang yang sama sehingga muncul di permintaan penarikan yang ada.

Untuk perubahan terjemahan, lihat [Terjemahkan aplikasi](TRANSLATIONS.md).
