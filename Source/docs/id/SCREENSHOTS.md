## Segarkan gambar panduan

Dari folder solusi, jalankan `./scripts/capture-docs.ps1` di Windows. Ia menggunakan data sampel dan menulis PNG ke `docs/images/screenshots/<version>/<language>/`. Ini mencakup semua penayangan dalam tabel untuk bahasa Inggris, Denmark, dan Jerman, dan enam penayangan untuk masing-masing dari sembilan bahasa lainnya. Skrip ini juga menangkap [panduan cepat berbahasa Denmark yang diberi anotasi](../images/screenshots/1.0.1/da/quick-guide.png).

Gunakan penskalaan tampilan 100% dan area kerja minimal 1440 × 800 untuk jendela penuh. Tinjau tangkapan sebelum memperbarui README dan panduan. Simpan folder dan file tangkapan layar sebelumnya di jalur aslinya sehingga tautan rilis lama tetap berfungsi.
