## Segarkan gambar panduan

Dari folder solusi, jalankan `./scripts/capture-docs.ps1` di Windows. Ia menggunakan data sampel dan menulis PNG ke `docs/images/screenshots/<version>/<language>/`. Skrip mengambil gambar semua tampilan dan panduan cepat beranotasi dalam 12 bahasa.

Gunakan penskalaan tampilan 100% dan area kerja minimal 1440 × 800 untuk jendela penuh. Tinjau tangkapan sebelum memperbarui README dan panduan. Simpan folder dan file tangkapan layar sebelumnya di jalur aslinya sehingga tautan rilis lama tetap berfungsi.
