# Laporkan masalah

1. Buka panel pengaturan. Pilih **Kontak dan Tentang → Kontak → Laporkan masalah**.
2. Jika ada versi yang lebih baru, pilih **Ya** untuk membuka halaman unduh. Instal versi itu dan periksa apakah masalah masih dapat diulangi. Pilih **Tidak** untuk melanjutkan ke draf GitHub.
3. Jika aplikasi menawarkan ZIP dukungan, pilih **Ya** dan tentukan tempat menyimpannya. Pilih **Tidak** untuk membuka draf tanpa membuat arsip.

![Tab kontak dengan tombol GitHub dan ZIP dukungan](../images/screenshots/contact/id/issues.png)

## Tambahkan rincian dan lampirkan ZIP

Tombol membuka templat **Bug report** di GitHub. Jelaskan hasil yang diharapkan, kejadian sebenarnya, dan cara mengulanginya. Cantumkan versi aplikasi dan Windows. Sebutkan kamera dan aplikasi perekam jika relevan. Isi setiap bagian yang ditandai dengan tanda bintang merah.

Pilih **Kontak dan Tentang → Kontak → Simpan ZIP dukungan** dan tentukan lokasi penyimpanan. Aplikasi menampilkan jalur berkas.

ZIP berisi tangkapan layar aplikasi, `profiles.json` yang tersimpan, tata letak jendela dalam `window.json`, dan log yang tersedia di `Logs`.

Periksa dan singkirkan informasi pribadi, seperti nama profil, ID kamera, dan jalur berkas. Seret sendiri ZIP atau berkas yang relevan ke kolom deskripsi draf.

![Draf GitHub dengan deskripsi, area lampiran, dan tombol Create](../images/reporting/github-new-issue.png)

## Periksa jenis dan label

Templat meminta **Bug** di **Type** dan `bug` di **Labels**. Jika belum terisi dan dapat diedit, pilih nilainya di bilah sisi kanan. Jika tidak dapat mengubahnya, kirim draf. Pengelola proyek dapat mengisinya nanti.

![Menu Type GitHub dengan pilihan Bug, Task, dan Feature](../images/reporting/github-issue-type.png)

![Menu Labels GitHub](../images/reporting/github-issue-labels.png)

Periksa deskripsi dan lampiran di **Preview**, lalu pilih **Create**.
