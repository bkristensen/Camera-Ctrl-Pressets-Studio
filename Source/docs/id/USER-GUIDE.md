# Penggunaan dan pengaturan

[Bahasa Indonesia · Camera Control Studio](../USER-GUIDES.md)

![Jendela utama dengan panel pengaturan tertutup](../images/screenshots/main.png)

1. Jika perangkat lunak perekaman atau siaran harus terhubung lebih dulu, jalankan sebelum membuka Camera Control Studio. Pilih profil di bagian bawah jendela. Untuk mengganti kamera, klik ikon kamera di tengah roda arah.
2. Gunakan panah dalam untuk memutar atau memiringkan kamera dengan kecepatan normal dan panah luar untuk langkah cepat. Gunakan tombol kaca pembesar untuk zoom. Seret lalu lepas penggeser vertikal untuk mengatur zoom langsung. Arah yang mencapai batas akan dinonaktifkan.
3. Klik ▶, klik dua kali nama preset, atau pilih baris lalu tekan Enter. Warna kuning menandakan kamera sedang bergerak. Warna hijau menandakan driver melaporkan posisi tersimpan telah tercapai. Periksa pembingkaian di perangkat lunak perekaman.
4. Klik **+** di atas daftar untuk menyimpan preset sementara. Pilih barisnya lalu klik **×** untuk menghapus. Preset sementara dihapus saat aplikasi ditutup. Untuk menyimpan posisi secara permanen, buka ikon roda gigi di bagian bawah, pilih **Preset → Tambah preset permanen**, tentukan nama dan ikon, lalu simpan.

   ![Preset permanen dan tombol pengelolaannya](../images/screenshots/presets.png)

5. Di Pengaturan, atur langkah, waktu transisi, dan pembalikan arah. Tab **Video** memuat kontrol yang tersedia pada driver. Gunakan tab **Profil** untuk membuat atau menyalin profil. Aktifkan konfirmasi siaran jika perangkat lunak perekaman perlu terhubung terlebih dahulu.

   ![Tab Pengaturan dengan opsi gerakan dan bahasa](../images/screenshots/settings.png)

6. Seret pemisah vertikal untuk mengatur lebar kedua area. Panel pengaturan selalu tertutup saat aplikasi dimulai. Pilih **Pengaturan → Bahasa** dan mulai ulang aplikasi. Arahkan kursor ke tombol kecil untuk melihat keterangannya.
