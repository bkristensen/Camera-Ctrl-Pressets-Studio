# Camera Control Studio उपयोगकर्ता मार्गदर्शिकाएँ

*Camera Control Studio 1.0.1.* के लिए लिखा गया

इंस्टॉलर और पोर्टेबल ZIP गाइड शामिल करें. क्लिक करें **?** अपनी प्रोफ़ाइल की भाषा में स्थानीय गाइड खोलने के लिए। परिवर्तन **गाइड की भाषा** एक अलग अनुवाद पढ़ने के लिए. चुनें **ऑनलाइन गाइड इस्तेमाल करें** नवीनतम से गाइड पढ़ने के लिए GitHub रिहाई. यदि उस रिलीज़ का कोई अनुवाद नहीं है, तो दर्शक अंग्रेज़ी आज़माता है। यदि ऑनलाइन गाइड अनुपलब्ध है, तो उपलब्ध होने पर यह स्थानीय प्रति दिखाता है। सीधे सेटअप पर जाने के लिए सबसे पहले सेटिंग्स खोलें। क्लिक करें **प्रिंट करें** वर्तमान गाइड को उसके शीर्षक, प्रिंट तिथि और समय, स्थापित संस्करण, प्रोजेक्ट पते और पृष्ठ संख्या के साथ प्रिंट करने के लिए।

दर्शक को चाहिए [माइक्रोसॉफ्ट एज WebView2 रनटाइम](https://developer.microsoft.com/microsoft-edge/webview2/). आप भी खोल सकते हैं **कैमरा नियंत्रण स्टूडियो उपयोगकर्ता मार्गदर्शिकाएँ** इंस्टॉल करने के बाद स्टार्ट मेनू से। पोर्टेबल संस्करण के लिए, खोलें `docs` निकाले गए फ़ोल्डर में ZIP.

<https://developer.microsoft.com/microsoft-edge/webview2/>
