# Camera Control Studio बनाएं और रिलीज़ करें

*Camera Control Studio 1.0.1.* के लिए लिखा गया

उस निर्देशिका से कमांड चलाएँ जिसमें `Camera-Control-Pressets-Studio.sln` है। इंस्टॉलर और विंडोज़ परीक्षण के लिए विंडोज़ और PowerShell का उपयोग करें।

## 1. विज्ञप्ति तैयार करें

1. रिलीज़ के लिए चयनित कमिट से प्रारंभ करें। अपग्रेड को संकलित करने या परीक्षण करने से पहले किसी भी चल रहे Camera Control Studio इंस्टेंस को बंद कर दें।
2. `global.json` द्वारा चयनित .NET 8 SDK स्थापित करें। यदि आप इंस्टॉलर प्रकाशित करने की योजना बना रहे हैं तो Inno Setup 6 या 7 इंस्टॉल करें। यदि आप SignTool के साथ फ़ाइलों पर हस्ताक्षर करने या MakeAppx के साथ MSIX बनाने की योजना बना रहे हैं तो Windows SDK स्थापित करें।
3. `./scripts/setup-dev.ps1 -CheckOnly` के साथ आवश्यक शर्तें जांचें। एक नए वर्कस्टेशन के लिए, `./scripts/setup-dev.ps1` पिन किए गए पैकेजों को पुनर्स्थापित करता है और पोर्टेबल बिल्ड चलाता है।
4. रिलीज़ संस्करण को `Directory.Build.props` में सेट करें और `CHANGELOG.md` को अपडेट करें। इंस्टॉलर स्क्रिप्ट बिल्ड गुणों से डिफ़ॉल्ट संस्करण को पढ़ती है। MSIX तैयार करते समय चार-भाग वाले स्टोर संस्करण को अलग रखें।

## 2. GitHub पैकेज बनाएं

एक आदेश चुनें. इंस्टॉलर बिल्ड में पोर्टेबल बिल्ड शामिल है।

| क्या बनाना है | आदेश | आउटपुट |
| --- | --- | --- |
| पोर्टेबल ZIP | `./scripts/build.ps1` | `artifacts/Camera-Control-Studio-portable.zip` |
| पोर्टेबल ZIP और इनो इंस्टॉलर | `./scripts/build-installer.ps1` | पोर्टेबल ZIP प्लस `artifacts/installers/CamCtrlStudio-Setup-<version>.exe` |

`build.ps1` अनुवादों की जाँच करता है, लॉक की गई निर्भरता के साथ रिलीज़ बनाता है, परीक्षण चलाता है और ZIP बनाता है। `CameraControlStudio/bin/Release/net48` में निष्पादन योग्य और `artifacts/portable/Camera-Control-Studio` में चरणबद्ध फ़ाइलें ढूंढें। संपूर्ण ZIP प्रकाशित करें। ऐप को इसके कॉन्फ़िगरेशन, लाइब्रेरी और गाइड की आवश्यकता है।

वर्तमान उपयोगकर्ता के विंडोज़ प्रमाणपत्र स्टोर में उपलब्ध किसी व्यक्ति या संगठन कोड-हस्ताक्षर प्रमाणपत्र का उपयोग करने के लिए, निर्माण करते समय उसके अंगूठे का निशान और पथ को SignTool पर पास करें। इंस्टॉलर कमांड एप्लिकेशन को पैक करने से पहले उस पर हस्ताक्षर करता है और टाइमस्टैम्प के साथ पूर्ण इंस्टॉलर पर हस्ताक्षर करता है।

```powershell
$thumbprint = '<certificate thumbprint>'
$signtool = '<full path to signtool.exe>'
./scripts/build-installer.ps1 -CertificateThumbprint $thumbprint -SignToolPath $signtool
```

अकेले ZIP के लिए, `build.ps1` को समान पैरामीटर दें। प्रायोजित हस्ताक्षर के लिए, अनुमोदित [SignPath वर्कफ़्लो](SIGNPATH.md) का पालन करें। अहस्ताक्षरित डाउनलोड को स्पष्ट रूप से चिह्नित करें।

## 3. विंडोज़ पर पैकेजों की जाँच करें

1. ZIP को एक नई निर्देशिका में निकालें। वहां से ऐप शुरू करें और सेटिंग्स बंद करके **?** खोलें। [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) स्थापित होने पर, गाइड नेविगेशन सत्यापित करें और शीर्षक, प्रिंट दिनांक और समय, स्थापित संस्करण, प्रोजेक्ट पता और पृष्ठ संख्या की जांच करने के लिए PDF पर प्रिंट करें। प्रोफ़ाइल स्विच करते समय ऐप संस्करण, लॉन्च व्यवहार, प्रीसेट, कैमरा नियंत्रण और भाषा चयन सत्यापित करें।
2. यदि आप इंस्टॉलर को प्रकाशित करने की योजना बना रहे हैं, तो इसे एक साफ़ विंडोज़ परीक्षण खाते पर इंस्टॉल करें। स्टार्ट मेनू ऐप और उपयोगकर्ता-गाइड शॉर्टकट सत्यापित करें। जांचें कि सभी 12 गाइड मौजूद हैं, कि अपग्रेड मौजूदा प्रोफाइल को बरकरार रखता है, और अनइंस्टॉल पूरा हो जाता है।
3. [रिलीज़ चेकलिस्ट](RELEASE-CHECKLIST.md) के माध्यम से कार्य करें। हस्ताक्षरित बिल्ड के लिए, ऐप निष्पादन योग्य और इंस्टॉलर पर SignTool सत्यापन चलाएँ। कोई भी हस्ताक्षर और पुनः पैकेजिंग समाप्त होने के बाद ही हैश उत्पन्न करें।

## 4. GitHub डाउनलोड को स्टेज और हैश करें

आगामी रिलीज़ के लिए इस उदाहरण में संस्करण बदलें। केवल ZIP रिलीज़ के लिए इंस्टॉलर पंक्तियों को हटा दें।

```powershell
$version = '1.0.0'
$release = "artifacts/releases/$version"
New-Item -ItemType Directory -Path $release -Force | Out-Null

$zip = "Camera-Control-Studio-$version-portable.zip"
$installer = "CamCtrlStudio-Setup-$version.exe"
Copy-Item 'artifacts/Camera-Control-Studio-portable.zip' (Join-Path $release $zip)
Copy-Item "artifacts/installers/$installer" $release
@($zip, $installer) | ForEach-Object {
    $hash = Get-FileHash -LiteralPath (Join-Path $release $_) -Algorithm SHA256
    '{0}  {1}' -f $hash.Hash.ToLowerInvariant(), $_
} | Set-Content -LiteralPath (Join-Path $release 'SHA256SUMS.txt') -Encoding ascii
```

संस्करणित फ़ोल्डर में अंतिम ZIP, इंस्टॉलर और SHA-256 मेनिफ़ेस्ट है। `bin` और पोर्टेबल स्टेजिंग निर्देशिकाएँ इस चरण के लिए निर्मित इनपुट हैं।

## 5. GitHub पर प्रकाशित करें

1. इस रिलीज़ के लिए आपके द्वारा समीक्षा की जाने वाली प्रत्येक मार्गदर्शिका में संस्करण उपशीर्षक को अपडेट करें। इसके अनुवादों को समकालिक रखें. रिलीज़ संस्करण, चेंजलॉग, गाइड और स्रोत परिवर्तन प्रतिबद्ध करें। [GitHubreleases](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/releases) में, एक ड्राफ्ट बनाएं और परीक्षण किए गए कमिट पर `v1.0.0` जैसे टैग का उपयोग करें।
2. मेल खाने वाले चेंजलॉग प्रविष्टि को रिलीज़ नोट्स में कॉपी करें, बताएं कि क्या डाउनलोड पर हस्ताक्षर किए गए हैं, और केवल पूर्वावलोकन बिल्ड के लिए प्रीरिलीज़ विकल्प का चयन करें।
3. संस्करणित ZIP, यदि बनाया गया है तो इंस्टॉलर और `artifacts/releases/<version>/` से `SHA256SUMS.txt` संलग्न करें। फ़ाइल नामों की समीक्षा करें, तैयार फ़ाइलों को डाउनलोड करें और सत्यापित करें, फिर प्रकाशित करें।
