# Camera Control Studio অনুবাদ করুন

* Camera Control Studio 1.1.1.* এর জন্য লেখা

## একটি বিদ্যমান ভাষা সম্পাদনা করুন

1. `Source/Shared/Locales/<code>.xml` খুলুন। প্রসঙ্গ এবং কীগুলির জন্য রেফারেন্স হিসাবে `en.xml` ব্যবহার করুন৷
2. `<text>` ট্যাগের মধ্যে পাঠ্য সম্পাদনা করুন। কী, প্লেসহোল্ডার যেমন `{0}`, এবং সংরক্ষিত আইডি অক্ষত রাখুন। UTF-8 হিসাবে সংরক্ষণ করুন। XML-এ, `&amp;` হিসাবে একটি আক্ষরিক অ্যাম্পারস্যান্ড লিখুন।
3. আপনি যদি সাহায্যও পরিবর্তন করেন, তাহলে `Source/docs`-এ মিলে যাওয়া ফোল্ডারটি সম্পাদনা করুন। গাইড ভিউয়ারে অন্যান্য গাইড এবং ছবির লিঙ্ক পরীক্ষা করুন।

## একটি ভাষা যোগ করুন

1. নতুন ভাষার কোডের জন্য একটি ফাইলে `en.xml` কপি করুন এবং সমস্ত মান অনুবাদ করুন।
2. `LanguageCodes` এবং `Source/Shared/UiText.cs`-এ `LanguageNames` একই সূচকে কোড এবং প্রদর্শনের নাম নিবন্ধন করুন। যেখানে প্রযোজ্য সেখানে ডান-থেকে-বাম হ্যান্ডলিং আপডেট করুন।
3. MSIX ম্যানিফেস্টে অ্যাপের ভাষা যোগ করুন। আপনি যদি ব্যবহারকারীর নির্দেশিকা যোগ করেন, তাহলে `Source/docs`-এর অধীনে বিদ্যমান ফোল্ডারের কাঠামো অনুসরণ করুন, এটি `USER-GUIDES.md`-এ যোগ করুন এবং গাইড ভিউয়ার এটি খোলে তা যাচাই করুন।

## যাচাই করে জমা দিন

`Source` থেকে, `powershell -File scripts/check-translations.ps1` চালান এবং তৈরি করুন। `--lang=<code>` দিয়ে অ্যাপটি শুরু করুন। সবচেয়ে ছোট উইন্ডো আকারে ডায়ালগ পরীক্ষা করুন এবং কীবোর্ড দিয়ে নেভিগেট করুন। লম্বা লেবেল, টেক্সট দিকনির্দেশ এবং স্থানধারক পূরণ করে এমন বার্তা পরীক্ষা করুন।

একটি পুল অনুরোধ খুলতে [GitHub প্রকল্প নির্দেশিকা](GITHUB.md) অনুসরণ করুন। ভাষা এবং কোডের নাম দিন, পরিবর্তনগুলি সংক্ষিপ্ত করুন এবং আপনি কী পরীক্ষা করেছেন তা জানান৷ একটি স্ক্রিনশট অন্তর্ভুক্ত করুন যদি এটি সমালোচকদের বিন্যাস মূল্যায়ন করতে সহায়তা করে। পর্যালোচনার সময় একই শাখায় ফলো-আপ সম্পাদনা যোগ করুন।
