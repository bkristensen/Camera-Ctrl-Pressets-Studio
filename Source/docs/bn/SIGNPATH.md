# কোড স্বাক্ষর নীতি

* Camera Control Studio 1.1.0.* এর জন্য লেখা

SignPath ফাউন্ডেশন যোগ্য ওপেন সোর্স প্রকল্পের জন্য বিনামূল্যে স্বাক্ষর করার প্রস্তাব দেয়। গ্রহণ প্রয়োজন. সার্টিফিকেট SignPath ফাউন্ডেশনকে প্রকাশক হিসেবে চিহ্নিত করে; পরিষেবা লিঙ্কগুলি উৎস সংগ্রহস্থলে যাচাইকৃত বিল্ড। প্রকল্পটি SignPath ফাউন্ডেশন স্বাক্ষরের জন্য আবেদন করেছে। অ্যাপ্লিকেশনটি মুলতুবি আছে, এবং GitHub ডাউনলোডগুলি স্বাক্ষরবিহীন থাকে৷

আপনি আবেদন করার আগে, এর লাইসেন্সের অধীনে উত্সটি প্রকাশ করুন। প্রকল্পটি বর্তমান রাখুন। একটি রিলিজ প্রকাশ করুন, অ্যাপটি নথিভুক্ত করুন এবং বিল্ডটিকে যাচাইযোগ্য করুন। শুধুমাত্র আপনার নিজস্ব প্রকল্প ফাইল সাইন ইন করুন. সংগ্রহস্থলের বাইরে শংসাপত্র স্বাক্ষর করতে থাকুন।

[ গোপনীয়তা নীতি](../../PRIVACY.md) অ্যাপ, এর GitHub আপডেট চেক এবং GuideViewer-এর WebView2 রানটাইমকে কভার করে।

## আবেদন মুলতুবি থাকা অবস্থায়

- **Actions** এর অধীনে পাবলিক রিপোজিটরিতে একটি সফল উইন্ডোজ বিল্ড আছে কিনা পরীক্ষা করুন। SignPath ইন্টিগ্রেশনের ভিত্তি হিসেবে সেই ওয়ার্কফ্লো ব্যবহার করুন।
- প্রতিশ্রুতি, পর্যালোচনা এবং স্বাক্ষর করার অনুমোদনের জন্য দায়ী ব্যক্তিদের নিশ্চিত করুন। GitHub এবং SignPath-এ সমস্ত দলের সদস্যদের জন্য মাল্টি-ফ্যাক্টর প্রমাণীকরণ চালু করুন।
- WebView2 SDK বাইনারি এবং Inno Setup ইনস্টলার কীভাবে পরিচালনা করা উচিত তা নিশ্চিত করতে SignPath কে জিজ্ঞাসা করুন৷ প্যাকেজগুলির মধ্যে Microsoft এর SDK বাইনারি এবং লোডার রয়েছে। অ্যাপটি ব্যবহারকারীর পিসিতে ইনস্টল করা WebView2 রানটাইম ব্যবহার করে। অ্যাপ্লিকেশনে এই নির্ভরতা তালিকাভুক্ত করুন এবং তাদের বিজ্ঞপ্তি সংরক্ষণ করুন।
- একটি যোগ করুন **কোড স্বাক্ষর নীতি** লিঙ্ক GitHub অ্যাপ্লিকেশনে সরবরাহ করা ডাউনলোড পৃষ্ঠার জন্য নোট রিলিজ করুন। সেই ডাউনলোডগুলির প্রকৃত সাইনিং স্থিতি বর্ণনা করুন৷

## SignPath প্রকল্প গ্রহণ করার পর

- অনুমোদিত SignPath অ্যাট্রিবিউশন এবং এই পৃষ্ঠায় প্রতিশ্রুতিদাতা, পর্যালোচক এবং অনুমোদনকারীদের জন্য নিশ্চিত নাম বা অনুমতি গোষ্ঠী যোগ করুন।
- বিশ্বস্ত GitHub Actions বিল্ড থেকে আর্টিফ্যাক্ট গ্রহণ করতে SignPath কনফিগার করুন। প্রকল্প বাইনারি সাইনিং সীমাবদ্ধ. একসাথে জমা দেওয়া ফাইল জুড়ে পণ্যের নাম এবং মানানসই পণ্য সংস্করণ সেট করুন এবং প্রয়োগ করুন।
- ZIP-এর জন্য, প্যাকেজিংয়ের আগে এক্সিকিউটেবল অ্যাপে সাইন ইন করুন। ইনস্টলারের জন্য, সমাপ্ত ইনস্টলারে স্বাক্ষর করার আগে স্বাক্ষরিত অ্যাপটি ইনস্টলারে কার্যকর করুন। প্রতিটি রিলিজ স্বাক্ষর করার অনুরোধের জন্য ম্যানুয়াল অনুমোদন পান।
- প্রামাণিক কোড স্বাক্ষর এবং টাইমস্ট্যাম্প যাচাই করুন, তারপর SHA-256 চেকসাম তৈরি করুন। রিলিজ নোটে একটি **Code স্বাক্ষর করার নীতি** লিঙ্ক এবং স্বাক্ষরের স্থিতি অন্তর্ভুক্ত করুন। আপলোড করা ফাইল এবং হ্যাশ প্রকাশ করার আগে যাচাই করুন।

সরাসরি GitHub ডাউনলোডের জন্য, একটি বৈধ স্বাক্ষর প্রকাশককে চিহ্নিত করে এবং বাইনারিটির অখণ্ডতা রক্ষা করে৷ খ্যাতি তৈরি হওয়ার সময় একটি নতুন ডাউনলোড এখনও স্মার্টস্ক্রিনকে ট্রিগার করতে পারে। স্টোরের মাধ্যমে প্রথম-চালিত বিতরণের জন্য, মাইক্রোসফ্ট MSIX প্যাকেজগুলি গ্রহণ করেছে৷

বর্তমান ব্যবহারকারীর Windows সার্টিফিকেট স্টোরের মাধ্যমে উপলব্ধ একটি সর্বজনীনভাবে বিশ্বস্ত কোড-সাইনিং শংসাপত্রের জন্য, পোর্টেবল ZIP-এর জন্য `scripts/build.ps1 -CertificateThumbprint <thumbprint> -SignToolPath <path>` ব্যবহার করুন৷ অ্যাপ্লিকেশান এক্সিকিউটেবল এবং জেনারেট করা ইনস্টলার উভয় সাইন করতে `scripts/build-installer.ps1` এর সাথে একই প্যারামিটার ব্যবহার করুন৷ SignPath অনুমোদনের জন্য নিজস্ব সাইনিং ওয়ার্কফ্লো প্রয়োজন।
