## একটি পরিবর্তন প্রস্তাব

1. [Contributing](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/blob/main/Source/CONTRIBUTING.md) পড়ুন এবং একটি সম্পর্কিত সমস্যা দেখুন বা অনুরোধ টানুন।
2. আপনার যদি লেখার অ্যাক্সেসের অভাব থাকে তবে সংগ্রহস্থলকে ফোর্ক করুন। প্রকল্পের `main` শাখা থেকে একটি শাখা তৈরি করুন।
3. একটি ফোকাসড পরিবর্তন করুন, এটি যাচাই করুন এবং একটি সংক্ষিপ্ত বিবরণ সহ এটি প্রতিশ্রুতিবদ্ধ করুন৷ আপনার কাঁটাচামচ শাখা ধাক্কা.
4. প্রকল্পের **Pull requests** ট্যাবে, `main` টার্গেট করে একটি পুল অনুরোধ খুলুন৷ কী পরিবর্তিত হয়েছে, আপনি কীভাবে এটি পরীক্ষা করেছেন তা ব্যাখ্যা করুন এবং সম্পর্কিত যেকোন সমস্যা লিঙ্ক করুন।
5. চেক এবং পর্যালোচনা অনুসরণ করুন. একই শাখায় সংশোধনগুলি পুশ করুন যাতে তারা বিদ্যমান পুল অনুরোধে উপস্থিত হয়।

অনুবাদের পরিবর্তনের জন্য, দেখুন [অ্যাপ্লিকেশানটি ](TRANSLATIONS.md) অনুবাদ করুন৷
