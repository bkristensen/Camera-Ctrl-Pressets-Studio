# ইন্টারফেস এবং অনুবাদ সম্পাদনা করুন

* Camera Control Studio 1.1.0.* এর জন্য লেখা

## ডান ফাইল খুলুন

খোলা `Camera-Control-Pressets-Studio.sln`. সমাধান এক্সপ্লোরারে, সমাধান তৈরি করুন, তারপর খুলুন `CameraControlStudio → Forms → MainForm.cs`. চাপুন **Shift+F7** জন্য Windows Forms Designer. নির্বাচন করবেন না `MainForm.Designer.cs` নকশা পৃষ্ঠ হিসাবে. কোডে ফিরে যেতে F7 ব্যবহার করুন।

Visual Studio .NET ডেস্কটপ ওয়ার্কলোড `.vsconfig` থেকে ইনস্টল করুন। অ্যাপ্লিকেশনটি হল .NET ফ্রেমওয়ার্ক 4.8-এ WinForms। WPF ডিজাইনার ব্যবহার করা হয় না।

## লেআউট পরিবর্তন করুন

`Dock`, `Margin`, `Padding`, সারি আকার এবং কলামের আকার পরিবর্তন করতে বৈশিষ্ট্য প্যানেল ব্যবহার করুন৷ নেস্টেড প্যানেল নির্বাচন করতে ডকুমেন্ট আউটলাইন ব্যবহার করুন। প্রধান লেআউট টেবিল এবং একটি `SplitContainer` ব্যবহার করে; হার্ড-কোডেড স্ক্রিন স্থানাঙ্ক এড়িয়ে চলুন।

প্রতিটি উইন্ডো `AppForm` থেকে উত্তরাধিকার সূত্রে প্রাপ্ত এবং প্যারামিটার ছাড়াই একটি পাবলিক কনস্ট্রাক্টর রয়েছে। `.Designer.cs`-এ লেআউট এবং ম্যাচিং `.cs` ফাইলে ইভেন্টগুলি রাখুন৷ ডিজাইনারে ফর্মের `Icon` সম্পত্তি সেট করুন। Visual Studio এবং চলমান অ্যাপে লেআউট পরীক্ষা করুন।

ক্যামেরার চাকা এবং নীল বোতাম `Controls/BlueControls.cs` এ আঁকা হয়েছে। উল্লম্ব বিভাজক এবং জুম নিয়ন্ত্রণগুলি `Controls/MainViewControls.cs`-এ রয়েছে৷ ডিজাইনার এই নিয়ন্ত্রণগুলি সরাতে এবং আকার দিতে পারে। প্রিসেট আইকন ইমেজ এবং তাদের নিরপেক্ষ শিরোনাম `Assets/PressetIcons.resx`, এবং `Controls/PresetIcons.cs` তাদের লোড করে। ভিডিও ট্যাবে ডিজাইনার-লেখক স্লাইডার রয়েছে। চলমান অ্যাপটি ক্যামেরা ড্রাইভার দ্বারা সমর্থিত স্লাইডারগুলি দেখায়।

## ডিফল্ট সেট করুন

নতুন-প্রোফাইল সেটিংসের জন্য `SavedData.Defaults`-এ, `Shared/Models.cs` সম্পাদনা করুন। প্রাথমিক লেআউটের জন্য `ProfileLayout` সম্পাদনা করুন। বিদ্যমান প্রোফাইলগুলি তাদের সংরক্ষিত মান ধরে রাখে। নতুন ডিফল্ট পরীক্ষা করার জন্য একটি নতুন প্রোফাইল তৈরি করুন; তাদের বাধ্য করার জন্য ব্যবহারকারীর প্রোফাইল মুছে ফেলবেন না।

## একটি অনুবাদ আপডেট করুন

`Shared/Locales` এর অধীনে প্রাসঙ্গিক ভাষার ফাইলে মিল মান সম্পাদনা করুন। `key` অপরিবর্তিত রাখুন। একটি অ্যাম্পারস্যান্ডের জন্য XML-এর `&amp;` প্রয়োজন৷ সমস্ত ফাইলের একই কী থাকতে হবে। সংরক্ষিত ক্যামেরা এবং আইকন আইডি অপরিবর্তিত রাখুন।

`scripts/check-translations.ps1` চালান, তারপর তৈরি করুন। `"Camera Control Studio.exe" --lang=de` বা সেটিংসে ভাষা নির্বাচকের সাথে পরীক্ষা করুন। সংরক্ষিত ভাষা পছন্দ পরিবর্তন করার পরে পুনরায় আরম্ভ করুন।

## একটি ভাষা যোগ করুন

একটি নতুন ভাষা-কোড ফাইলে `en.xml` অনুলিপি করুন। প্রতিটি মান অনুবাদ করুন এবং কোড এবং নাম `Shared/UiText.cs` এ নিবন্ধন করুন। অনুবাদ পরীক্ষক এবং লোকেল পরীক্ষা স্বয়ংক্রিয়ভাবে নতুন ফাইল এবং নিবন্ধন গ্রহণ করে। MSIX ম্যানিফেস্টে অ্যাপের ভাষা ঘোষণা করুন।

স্বয়ংক্রিয় নির্বাচন উইন্ডোজ ভাষা উপসর্গ ব্যবহার করে। অসমর্থিত ভাষাগুলি ইংরেজিতে ফিরে আসে। সংকীর্ণ জানালা এবং দীর্ঘ লেবেল পরীক্ষা করুন; অনুবাদ নিয়ন্ত্রণ লুকাতে হবে না।
