# রিলিজ চেকলিস্ট

* Camera Control Studio 1.1.1.* এর জন্য লেখা

[build ব্যবহার করুন এবং কমান্ড এবং আউটপুট পাথের জন্য গাইড](BUILD-AND-RELEASE.md) প্রকাশ করুন।

## স্বয়ংক্রিয় চেক

- [ ] লক করা নির্ভরতা সহ একটি পরিষ্কার চেকআউটে `scripts/build.ps1` চালান।
- [ ] নিশ্চিত করুন প্রতিটি লোকেলে একই অনন্য, খালি কী নেই৷ বিল্ড অনুবাদ চেক এবং লোকেল পরীক্ষা চালায়।
- [ ] উৎস এবং বাইনারি সংস্করণ, প্যাকেজ পরিচয় এবং রিলিজ নোট পর্যালোচনা করুন।

## উইন্ডোজ এবং ক্যামেরা চেক

- [ ] 900 × 500 এ লঞ্চ করুন এবং সর্বনিম্ন 670 × 450 যাচাই করুন। 100%, 125%, 150% এবং 200% ডিসপ্লে স্কেলিং এ আকার পরিবর্তন করুন, সর্বাধিক করুন এবং পুনরুদ্ধার করুন। ফুটার, ইনপুট, সম্মিলিত আইকন এবং জুম গ্লিফ পরীক্ষা করুন।
- [ ] ডানদিকে সেটিংস খুলুন। ডিভাইডার টানুন। বন্ধ করুন এবং পুনরায় খুলুন। একটি মনিটর সংযোগ বিচ্ছিন্ন করার পরে একটি সংরক্ষিত লেআউট পরীক্ষা করুন।
- [ ] একটি অবস্থান প্রত্যাহার করুন: চলাচলের সময় হলুদ, রিডব্যাক মেলে তবেই সবুজ। প্যান/টিল্ট/জুম সক্রিয় রঙ পরিষ্কার করে। একটি ট্রানজিশনের সময় সংযোগ বিচ্ছিন্ন করুন: কোন মিথ্যা সবুজ নয়। নিশ্চিতকরণের পরে আইকনগুলি কখনই অদৃশ্য হয় না।
- [ ] প্রতিটি বিপরীত ক্রম সহ প্রতিটি সম্মিলিত আইকন পরীক্ষা করুন। জুম বোতাম, জুম স্লাইডার এবং উভয় দিক বিপরীত পরীক্ষা করুন।
- [ ] একটি সমর্থিত Brio-এ, উভয় জুম দিক এবং বাম এবং ডান প্যান প্রান্তে স্বয়ংক্রিয় FOV পরীক্ষা করুন। [Brio পরীক্ষার ধাপ ](VALIDATION.md#brio-%E0%A6%AB%E0%A6%B2%E0%A6%A1-%E0%A6%85%E0%A6%AC-%E0%A6%AD%E0%A6%89-%E0%A6%8F%E0%A6%AC-%E0%A6%9C%E0%A6%AE) অনুসরণ করুন।
- [ ] ক্যামেরা নিশ্চিতকরণ সক্ষম করুন। রিস্টার্ট করুন। হ্যাঁ আগে কোন ক্যামেরা গণনা বা সংযোগ যাচাই করুন। পরীক্ষা না, তারপর একটি প্যান/জুম বোতাম থেকে পুনরায় চেষ্টা করুন। প্রোফাইল পরিবর্তন এবং উত্স নির্বাচন পরীক্ষা করুন।

## ডেটা এবং সম্পাদনা

- [ ] মাইগ্রেশনের আগে 0.6 প্রোফাইল ফাইলের ব্যাক আপ নিন। প্রিসেট এবং আইকন আইডি টিকে থাকা নিশ্চিত করুন। নিশ্চিত করুন অপ্রচলিত বহিরাগত-প্রোগ্রাম সেটিংস সংরক্ষণ করার পরে অনুপস্থিত।
- [ ] প্রোফাইলের নতুন/কপি/নাম পরিবর্তন করুন, লেআউট পুনরুদ্ধার করুন এবং বর্তমান-লেআউট আচরণ রাখুন। অস্থায়ী অবস্থানগুলি কেবলমাত্র সেশনে থাকবে যাচাই করুন।
- [ ] আসল ক্যামেরা দিয়ে ইমেজ স্বয়ংক্রিয়/ম্যানুয়াল সেটিংস এবং ডিফল্ট পরীক্ষা করুন।
- [ ] Visual Studio-এ Shift+F7 দিয়ে প্রতিটি ফর্ম খুলুন। একটি লেআউট সম্পত্তি সামঞ্জস্য করুন, সংরক্ষণ করুন এবং পুনর্নির্মাণ করুন। কাস্টম অঙ্কন নিয়ন্ত্রণ ক্লাসে থাকে।
- [ ] একটি 64-বিট উইন্ডোজ প্রক্রিয়ায় নিষ্কাশিত ZIP থেকে গাইড ভিউয়ার খুলুন। এটি আবার খুলুন এবং PDF-এ একটি গাইড প্রিন্ট করুন। ইনস্টলারটি নিশ্চিত করুন এবং ZIP প্রতিটি সমর্থিত আর্কিটেকচারের জন্য `runtimes` এর অধীনে ম্যাচিং WebView2 নেটিভ লোডার অন্তর্ভুক্ত করুন।
- [ ] [user-গাইড index](USER-GUIDES.md) চেক করুন এবং নিশ্চিত করুন যে প্রতিটি ভাষা নির্দেশিকা উভয় প্যাকেজে উপস্থিত রয়েছে। সম্পূর্ণ ট্যাব এবং সাবট্যাব কভারেজ, ক্রপিং এবং ওভারল্যাপের জন্য [guide স্ক্রিনশট](SCREENSHOTS.md) চেক করুন।

## বিতরণ

- [ ] পোর্টেবল রিলিজের জন্য, `scripts/build.ps1` ব্যবহার করুন। একটি Inno Setup ইনস্টলারের জন্য, `scripts/build-installer.ps1` ব্যবহার করুন, যা বহনযোগ্য বিল্ড এবং পরীক্ষা চালায়। ইনস্টলার এবং অ্যাপ দ্বারা দেখানো সংস্করণ যাচাই করুন।
- [ ] স্টোর রিলিজের জন্য, [Store চেকলিস্ট](MSIX-AND-STORE.md) অনুসরণ করুন। আপনি Windows এ প্রকাশ করার পরিকল্পনা করছেন এমন প্যাকেজ প্রকারগুলি পরীক্ষা করুন।
- [ ] যদি স্বাক্ষর করা হয়, যেখানে প্রযোজ্য অ্যাপ এক্সিকিউটেবল এবং ইনস্টলারে প্রমাণীকরণের স্বাক্ষর যাচাই করুন। স্বাক্ষরবিহীন ডাউনলোডগুলিকে স্পষ্টভাবে লেবেল করুন। চূড়ান্ত স্বাক্ষর এবং প্যাকেজিংয়ের পরে SHA-256 হ্যাশ তৈরি করুন।
- [ ] লিঙ্ক [কোড স্বাক্ষর নীতি](SIGNPATH.md) মধ্যে GitHub রিলিজ নোট জন্য SignPath প্রকাশ, বিল্ড প্রোভেন্যান্স এবং ম্যানুয়াল অনুমোদন এবং ক্রেডিট যাচাই করুন SignPath এটি স্বাক্ষরিত ফাইলগুলির জন্য।
- [ ] উত্স, লাইসেন্স, রিলিজ নোট, হ্যাশ এবং বাইনারি একসাথে প্রকাশ করুন। অকার্যকর হার্ডওয়্যার পরীক্ষা বা স্টোর অনুমোদন দাবি করবেন না।
