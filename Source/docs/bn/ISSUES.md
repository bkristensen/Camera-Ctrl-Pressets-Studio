## রিপোর্ট করার আগে অনুসন্ধান করুন

** একটি বাগ রিপোর্ট করুন বা একটি বৈশিষ্ট্য ** প্রস্তাব করুন৷\
<https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/issues?q=is%3Aissue>\
![প্রকল্পের জন্য QR কোড GitHub সমস্যা](../images/qr/issues.png)

1. প্রকল্পের [Issues ট্যাব](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/issues?q=is%3Aissue) খুলুন। উপসর্গ বা অনুরোধ থেকে মূল পদের জন্য অনুসন্ধান করুন, যেমন `is:issue Brio zoom` বা `is:issue label:enhancement preset`।
2. খোলা এবং বন্ধ ফলাফল পরীক্ষা করুন. মিলিত লক্ষণ এবং সমাধানের জন্য অনুরূপ প্রতিবেদন পড়ুন।
3. একটি মিলে যাওয়া ইস্যুতে, আপডেট পেতে সাইডবারে **Subscribe** নির্বাচন করুন বা এটি আপনাকে প্রভাবিত করে তা দেখানোর জন্য 👍 এর সাথে প্রতিক্রিয়া দেখান। আপনি যদি একটি ভিন্ন ক্যামেরা, একটি পরীক্ষার ফলাফল বা একটি নির্ভরযোগ্য প্রজননের মতো বিশদ বিবরণ দিতে পারেন তাহলে একটি মন্তব্য যোগ করুন।

## একটি প্রতিবেদন খুলুন

সেটিংস প্যানেল খুলুন। **যোগাযোগ ও পরিচিতি → যোগাযোগ** বেছে নিন। সঠিক GitHub খসড়া খুলতে **সমস্যা জানান** বা **নতুন ফিচারের অনুরোধ করুন** বেছে নিন। সমস্যা জানালে অ্যাপ সহায়তা ZIP সেভ করার সুযোগ দেয়। ZIP দেখে নিজে খসড়ায় যোগ করুন। [সমস্যা জানান](Report%20a%20bug.md) · [নতুন ফিচারের অনুরোধ করুন](Request%20a%20feature.md)

একটি বাগের জন্য, Camera Control Studio সংস্করণ, উইন্ডোজ সংস্করণ, ক্যামেরা মডেল, প্রাসঙ্গিক ক্যামেরা বা ক্যাপচার সফ্টওয়্যার এবং আপনি যে ক্রমে অ্যাপগুলি শুরু করেছেন তা অন্তর্ভুক্ত করুন৷ সঠিক পদক্ষেপগুলি বর্ণনা করুন, আপনি কী আশা করেছিলেন, কী ঘটেছে এবং কতবার। একটি অনুরোধের জন্য, আপনি যে কাজটি সম্পন্ন করতে চান এবং আপনি কীভাবে বৈশিষ্ট্যটি ব্যবহার করবেন তা বর্ণনা করুন।

![শিরোনাম, বিবরণ, ফাইল আপলোড এবং তৈরি বোতাম সহ GitHub সমস্যা সম্পাদক](../images/reporting/github-new-issue.png)

**Type** উপলব্ধ থাকলে, অপ্রত্যাশিত আচরণের জন্য **Bug** ব্যবহার করুন, একটি অনুরোধের জন্য **Feature**, অথবা কাজের জন্য **Task** ব্যবহার করুন। আপনি যদি লেবেল প্রয়োগ করতে পারেন, তাহলে সবচেয়ে প্রাসঙ্গিক ব্যবহার করুন, যেমন `bug`, `enhancement`, `documentation` বা `accessibility`। রক্ষণাবেক্ষণকারীরা জমা দেওয়ার পরে মেটাডেটা যোগ করতে পারেন।

## প্রমাণ সংযুক্ত করুন

প্যাকেজ সেভ করতে **যোগাযোগ ও পরিচিতি → যোগাযোগ → সহায়তা ZIP সংরক্ষণ করুন** বেছে নিয়ে স্থান ঠিক করুন। অ্যাপ ফাইলের পাথ দেখায়।

ZIP-এ অ্যাপের স্ক্রিনশট, সেভ করা `profiles.json`, উইন্ডোর বিন্যাসসহ `window.json` এবং `Logs`-এ থাকা লগ রয়েছে।

শেয়ার করার আগে প্রোফাইলের নাম, ক্যামেরার ID ও ফাইলের পাথের মতো ব্যক্তিগত তথ্য সরান। ZIP বা দরকারি ফাইলগুলো নিজে খসড়ার বিবরণে টেনে দিন।

**Preview**-তে বিবরণ ও সংযুক্ত ফাইল দেখুন। তারপর **Create** বেছে নিন।
