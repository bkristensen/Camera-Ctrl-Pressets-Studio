# Camera Control Studio ব্যবহারকারীর নির্দেশিকা

* Camera Control Studio 1.1.1.* এর জন্য লেখা

ইনস্টলার এবং বহনযোগ্য ZIP গাইড অন্তর্ভুক্ত করুন। ক্লিক করুন **?** আপনার প্রোফাইলের ভাষায় স্থানীয় গাইড খুলতে। পরিবর্তন **নির্দেশিকার ভাষা** একটি ভিন্ন অনুবাদ পড়তে। বেছে নিন **অনলাইন নির্দেশিকা ব্যবহার করুন** সর্বশেষ থেকে গাইড পড়তে GitHub মুক্তি যদি সেই রিলিজের কোন অনুবাদ না থাকে, দর্শক ইংরেজিতে চেষ্টা করে। অনলাইন গাইড অনুপলব্ধ হলে, এটি স্থানীয় অনুলিপি দেখায় যখন উপলব্ধ. সরাসরি সেটআপে যেতে প্রথমে সেটিংস খুলুন। ক্লিক করুন **প্রিন্ট করুন** বর্তমান গাইডের শিরোনাম, মুদ্রণের তারিখ এবং সময়, ইনস্টল করা সংস্করণ, প্রকল্পের ঠিকানা এবং পৃষ্ঠা নম্বর সহ মুদ্রণ করতে।

আপডেটের উৎস Microsoft Store হলে ভিউয়ার ইনস্টল করা সংস্করণের অনলাইন গাইড খোঁজে।

দর্শকের প্রয়োজন [মাইক্রোসফট এজ WebView2 রানটাইম](https://developer.microsoft.com/microsoft-edge/webview2/). খুলতেও পারেন **ক্যামেরা কন্ট্রোল স্টুডিও ব্যবহারকারী নির্দেশিকা** ইনস্টল করার পরে স্টার্ট মেনু থেকে। পোর্টেবল সংস্করণের জন্য, খুলুন `docs` এক্সট্রাক্ট করা ফোল্ডারে ZIP.

<https://developer.microsoft.com/microsoft-edge/webview2/>
