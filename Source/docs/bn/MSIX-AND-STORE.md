# MSIX এবং স্টোর বিতরণ

একটি MSIX প্যাকেজ তৈরি করতে `scripts/build-msix.ps1` এবং ম্যানিফেস্ট টেমপ্লেট ব্যবহার করুন৷ স্টোরে উপস্থিত হওয়ার আগে Microsoft প্যাকেজটি পর্যালোচনা করে। পোর্টেবল এক্সিকিউটেবল স্বাক্ষরবিহীন।

## একটি রুট চয়ন করুন

| রুট | স্বাক্ষর করছে |
| --- | --- |
| MSIX সহ মাইক্রোসফ্ট স্টোর | Microsoft স্বীকৃত স্টোর প্যাকেজ স্বাক্ষর করে। আপনি এই রুটের জন্য একটি স্বাক্ষর শংসাপত্র কিনবেন না৷ |
| একটি EXE/MSI ইনস্টলার সহ Microsoft স্টোর | প্রকাশকের স্বাক্ষর প্রয়োজন; স্টোর সেই ইনস্টলারটি পুনরায় স্বাক্ষর করে না। |
| সরাসরি MSIX ডাউনলোড | প্যাকেজটিতে অবশ্যই ব্যবহারকারীর ডিভাইসে বিশ্বস্ত স্বাক্ষর থাকতে হবে। |
| সরাসরি পোর্টেবল EXE | একটি স্বাক্ষরবিহীন বিল্ড সতর্কতা তৈরি করতে পারে। স্বাক্ষর প্রকাশককে চিহ্নিত করে কিন্তু তাৎক্ষণিক খ্যাতির প্রতিশ্রুতি দেয় না। |

## চেকলিস্ট

- [ ] পণ্যটি নিবন্ধন করুন এবং এটির নাম Partner Center এ সংরক্ষণ করুন। সঠিক প্যাকেজের নাম, প্রকাশক এবং প্রকাশক ডিসপ্লেনাম অনুলিপি করুন।
- [ ] Windows SDK টুলগুলি ইনস্টল করুন এবং সেই পরিচয় মানগুলি ব্যবহার করে নীচের কমান্ডটি চালান৷
- [ ] ম্যানিফেস্ট যাচাই করুন এবং Windows-এ ক্যামেরা অ্যাক্সেস, ইনস্টল, আপগ্রেড, আনইনস্টল, প্রোফাইল স্টোরেজ এবং ভাষা পরীক্ষা করুন। টেমপ্লেট ডেস্কটপ/ফুল-ট্রাস্ট অপারেশন এবং ওয়েবক্যাম অ্যাক্সেস ঘোষণা করে। এই মেলে বর্তমান সার্টিফিকেশন প্রয়োজনীয়তা যাচাই করুন.
- [ ] তালিকা, গোপনীয়তা নীতি, সমর্থন লিঙ্ক, লাইসেন্স তথ্য, বয়স রেটিং এবং বাস্তব স্ক্রিনশট প্রস্তুত করুন। প্রয়োজনীয় ক্যামেরা-চালক নিয়ন্ত্রণ ব্যাখ্যা করুন। বর্তমান Windows অ্যাপ সার্টিফিকেশন পরীক্ষা চালান।
- [ ] প্রার্থীকে Partner Center এ আপলোড করুন, যাচাইকরণের সমস্যাগুলি সমাধান করুন, জমা দিন এবং শংসাপত্রের জন্য অপেক্ষা করুন৷ অনুমোদনের আগে অ্যাপটিকে স্টোর-অনুমোদিত হিসাবে বর্ণনা করবেন না।

```powershell
./scripts/build-msix.ps1 -IdentityName 'YOUR.PRODUCT.IDENTITY' -Publisher 'CN=YOUR-PARTNER-CENTER-ID' -PublisherDisplayName 'YOUR DISPLAY NAME'
```

আউটপুটটি একটি স্বাক্ষরবিহীন স্টোর-জমা প্রার্থী, পাবলিক সাইডলোড প্যাকেজ ইনস্টল করার জন্য প্রস্তুত নয়। স্ক্রিপ্ট প্রয়োজনীয় পরিচয় ক্ষেত্র যাচাই করে এবং একটি স্পষ্ট x64 বিল্ড ব্যবহার করে। স্টোর জমা দেওয়ার জন্য চূড়ান্ত অংশ শূন্য সহ প্রতিটি রিলিজের জন্য একটি নতুন চার-অংশের প্যাকেজ সংস্করণ চয়ন করুন।

অফিসিয়াল রেফারেন্স, 18 নভেম্বর 2026 চেক করা হয়েছে:

- [Microsoft কোড সাইনিং বিকল্প ](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/code-signing-options)
- [Store প্রস্তুতির চেকলিস্ট](https://learn.microsoft.com/en-us/windows/apps/publish/store-readiness-checklist)
- [MSIX স্বাক্ষরকারী নির্দেশিকা](https://learn.microsoft.com/en-us/windows/msix/package/sign-msix-package-guide)

আরও দেখুন [SignPath](SIGNPATH.md)। বর্তমান যোগ্যতা এবং জমা দেওয়ার নিয়মগুলি প্রকাশের আগে আবার পরীক্ষা করা উচিত।
