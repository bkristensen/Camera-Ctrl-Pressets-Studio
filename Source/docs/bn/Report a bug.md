# সমস্যা জানান

* Camera Control Studio 1.1.0.* এর জন্য লেখা

1. উইন্ডোর নিচে গিয়ার বোতামে ক্লিক করে সেটিংস খুলুন। **যোগাযোগ ও পরিচিতি → যোগাযোগ → সমস্যা জানান** বেছে নিন।
2. নতুন সংস্করণ থাকলে ডাউনলোড পাতা খুলতে **হ্যাঁ** বেছে নিন। সেটি ইনস্টল করে সমস্যাটি আবার হয় কি না দেখুন। GitHub খসড়ায় যেতে **না** বেছে নিন।
3. অ্যাপ সহায়তা ZIP সেভ করতে বললে **হ্যাঁ** বেছে নিয়ে কোথায় রাখবেন ঠিক করুন। ZIP ছাড়া খসড়া খুলতে **না** বেছে নিন।

গাইড ভিউয়ারেও একই GitHub বোতাম আছে।

![GitHub ও সহায়তা ZIP-এর বোতামসহ যোগাযোগ ট্যাব](../images/screenshots/1.1.0/bn/issues.png)

## বিবরণ দিন ও ZIP সংযুক্ত করুন

বোতামটি GitHub-এর **Bug report** টেমপ্লেট খোলে। কী আশা করেছিলেন, কী ঘটেছে এবং আবার কীভাবে সমস্যাটি দেখা যাবে তা লিখুন। অ্যাপ ও Windows-এর সংস্করণ দিন। প্রাসঙ্গিক হলে ক্যামেরা ও ক্যাপচার অ্যাপের নাম দিন। লাল তারকা চিহ্ন দেওয়া সব অংশ পূরণ করুন।

প্যাকেজ সেভ করতে **যোগাযোগ ও পরিচিতি → যোগাযোগ → সহায়তা ZIP সংরক্ষণ করুন** বেছে নিয়ে স্থান ঠিক করুন। অ্যাপ ফাইলের পাথ দেখায়।

ZIP-এ অ্যাপের স্ক্রিনশট, সেভ করা `profiles.json`, উইন্ডোর বিন্যাসসহ `window.json` এবং `Logs`-এ থাকা লগ রয়েছে।

শেয়ার করার আগে প্রোফাইলের নাম, ক্যামেরার ID ও ফাইলের পাথের মতো ব্যক্তিগত তথ্য সরান। ZIP বা দরকারি ফাইলগুলো নিজে খসড়ার বিবরণে টেনে দিন।

![বিবরণ, ফাইল সংযুক্তির জায়গা ও Create বোতামসহ GitHub খসড়া](../images/reporting/github-new-issue.png)

## ধরন ও লেবেল যাচাই করুন

টেমপ্লেট **Type**-এ **Bug** এবং **Labels**-এ `bug` চায়। মানগুলো না থাকলে এবং সম্পাদনার সুযোগ থাকলে ডান দিকের সাইডবার থেকে বেছে নিন। সুযোগ না থাকলে খসড়া জমা দিন। প্রকল্পের রক্ষণাবেক্ষণকারীরা পরে যোগ করতে পারবেন।

![GitHub-এর Type মেনুতে Bug, Task ও Feature](../images/reporting/github-issue-type.png)

![GitHub-এর Labels মেনু](../images/reporting/github-issue-labels.png)
