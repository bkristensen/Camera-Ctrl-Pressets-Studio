# کسی مسئلے کی اطلاع دیں یا اس کی پیروی کریں۔

* Camera Control Studio 1.0.1.* کے لیے لکھا گیا

[Troublehooting](TROUBLESHOOTING.md)

## رپورٹ کرنے سے پہلے تلاش کریں۔

**کسی بگ کی اطلاع دیں یا کوئی خصوصیت تجویز کریں۔**\
<https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/issues?q=is%3Aissue>\
![پروجیکٹ کے لیے QR کوڈ GitHub مسائل](../images/qr/issues.png)

1. پروجیکٹ کا [Issues tab](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/issues?q=is%3Aissue) کھولیں۔ علامت یا درخواست سے کلیدی اصطلاحات تلاش کریں، جیسے `is:issue Brio zoom` یا `is:issue label:enhancement preset`۔
2. کھلے اور بند نتائج چیک کریں۔ مماثل علامات اور حل کے لیے اسی طرح کی رپورٹس پڑھیں۔
3. مماثل مسئلے پر، اپ ڈیٹس حاصل کرنے کے لیے سائڈبار میں **Subscribe** کو منتخب کریں، یا 👍 کے ساتھ رد عمل ظاہر کریں تاکہ یہ ظاہر ہو کہ یہ آپ کو متاثر کرتا ہے۔ ایک تبصرہ شامل کریں اگر آپ تفصیلات فراہم کر سکتے ہیں جیسے کہ ایک مختلف کیمرہ، ٹیسٹ کا نتیجہ یا قابل اعتماد تولید۔

![Isue کھولیں اور بند ٹیبز کے اوپر تلاش کریں۔ نیا شمارہ اوپری دائیں طرف ہے۔](../images/reporting/github-issues.png)

## ایک رپورٹ کھولیں۔

ترتیبات کا پینل کھولیں۔ **رابطہ اور تعارف → رابطہ** منتخب کریں۔ درست GitHub مسودے کے لیے **مسئلے کی اطلاع دیں** یا **نئی سہولت کی درخواست کریں** منتخب کریں۔ مسئلہ رپورٹ کرتے وقت ایپ معاونت کی ZIP پیش کرتی ہے۔ اسے دیکھ کر خود مسودے میں شامل کریں۔ [مسئلے کی اطلاع دیں](Report%20a%20bug.md) · [نئی سہولت کی درخواست کریں](Request%20a%20feature.md)

بگ کے لیے، Camera Control Studio ورژن، ونڈوز ورژن، کیمرہ ماڈل، متعلقہ کیمرہ یا کیپچر سافٹ ویئر، اور وہ ترتیب جس میں آپ نے ایپس شروع کی ہیں۔ درست اقدامات کی وضاحت کریں، آپ کیا توقع کرتے ہیں، کیا ہوا اور کتنی بار۔ درخواست کے لیے، اس کام کی وضاحت کریں جسے آپ پورا کرنا چاہتے ہیں اور آپ اس فیچر کو کس طرح استعمال کریں گے۔

![GitHub عنوان، تفصیل، فائل اپ لوڈ اور بٹن تخلیق کے ساتھ ایشو ایڈیٹر](../images/reporting/github-new-issue.png)

اگر **Type** دستیاب ہے تو، غیر متوقع رویے کے لیے **Bug**، درخواست کے لیے **Feature**، یا کام کے لیے **Task** کا استعمال کریں۔ اگر آپ لیبل لگا سکتے ہیں تو سب سے زیادہ متعلقہ لیبل استعمال کریں، جیسے `bug`، `enhancement`، `documentation` یا `accessibility`۔ مینٹینرز جمع کرانے کے بعد میٹا ڈیٹا شامل کر سکتے ہیں۔

## ثبوت منسلک کریں۔

پیکیج محفوظ کرنے کے لیے **رابطہ اور تعارف → رابطہ → معاونت کی ZIP محفوظ کریں** اور جگہ منتخب کریں۔ ایپ فائل کا راستہ دکھاتی ہے۔

ZIP میں ایپ کا اسکرین شاٹ، محفوظ شدہ `profiles.json`، ونڈو ترتیب والی `window.json` اور `Logs` میں موجود لاگز ہوتے ہیں۔

شیئر کرنے سے پہلے پروفائل کے نام، کیمرا ID اور فائل کے راستے جیسی ذاتی معلومات ہٹا دیں۔ ZIP یا متعلقہ فائلیں خود مسودے کی تفصیل میں گھسیٹ کر شامل کریں۔

**Preview** میں تفصیل اور منسلک فائلیں دیکھیں، پھر **Create** منتخب کریں۔

[GitHub مسئلہ تلاش کا حوالہ](https://docs.github.com/en/search-github/searching-on-github/searching-issues-and-pull-requests)
