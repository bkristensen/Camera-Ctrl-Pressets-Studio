# نئی سہولت کی درخواست کریں

* Camera Control Studio 1.1.0.* کے لیے لکھا گیا

1. ترتیبات کھولنے کے لیے نیچے گیئر کے بٹن پر کلک کریں۔ **رابطہ اور تعارف → رابطہ → نئی سہولت کی درخواست کریں** منتخب کریں۔
2. نیا ورژن دستیاب ہو تو ڈاؤن لوڈ صفحہ کھولنے کے لیے **ہاں** منتخب کریں۔ اسے انسٹال کریں اور دیکھیں کہ اس میں سہولت پہلے سے موجود ہے یا نہیں۔ GitHub کے مسودے پر جانے کے لیے **نہیں** منتخب کریں۔
3. GitHub کے **Feature request** سانچے میں اپنا کام، سہولت کا فائدہ اور وہ نتیجہ بتائیں جس سے معلوم ہو کہ سہولت کام کرتی ہے۔ سرخ ستارے والے تمام حصے پُر کریں۔

گائیڈ ویوئر میں بھی یہی GitHub بٹن ہیں۔

![GitHub اور معاونت کی ZIP کے بٹنوں والا رابطہ ٹیب](../images/screenshots/1.1.0/ur/issues.png)

## ایک مثال منسلک کریں

پیکیج محفوظ کرنے کے لیے **رابطہ اور تعارف → رابطہ → معاونت کی ZIP محفوظ کریں** اور جگہ منتخب کریں۔ ایپ فائل کا راستہ دکھاتی ہے۔

ZIP میں ایپ کا اسکرین شاٹ، محفوظ شدہ `profiles.json`، ونڈو ترتیب والی `window.json` اور `Logs` میں موجود لاگز ہوتے ہیں۔

شیئر کرنے سے پہلے پروفائل کے نام، کیمرا ID اور فائل کے راستے جیسی ذاتی معلومات ہٹا دیں۔ ZIP یا متعلقہ فائلیں خود مسودے کی تفصیل میں گھسیٹ کر شامل کریں۔

![تفصیل، منسلکات کی جگہ اور Create بٹن والا GitHub مسودہ](../images/reporting/github-new-issue.png)

## قسم اور لیبل دیکھیں

سانچہ **Type** میں **Feature** اور **Labels** میں `enhancement` مانگتا ہے۔ اگر خانے خالی ہیں اور قابلِ ترمیم ہیں تو دائیں جانب سے درست اقدار منتخب کریں۔ اجازت نہ ہو تو مسودہ بھیج دیں۔ منصوبے کا منتظم بعد میں اقدار شامل کر سکتا ہے۔

![GitHub کے Type مینو میں Bug، Task اور Feature](../images/reporting/github-issue-type.png)

![GitHub کا Labels مینو](../images/reporting/github-issue-labels.png)

**Preview** میں تفصیل اور منسلک فائلیں دیکھیں، پھر **Create** منتخب کریں۔
