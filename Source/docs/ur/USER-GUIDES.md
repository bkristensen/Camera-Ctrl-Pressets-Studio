# Camera Control Studio صارف کے رہنما

* Camera Control Studio 1.0.1.* کے لیے لکھا گیا

انسٹالر اور پورٹیبل ZIP رہنما شامل ہیں. کلک کریں۔ **?** مقامی گائیڈز کو اپنے پروفائل کی زبان میں کھولنے کے لیے۔ تبدیلی **رہنما کی زبان** ایک مختلف ترجمہ پڑھنے کے لیے۔ منتخب کریں۔ **آن لائن رہنما استعمال کریں** تازہ ترین سے گائیڈ کو پڑھنے کے لیے GitHub رہائی اگر اس ریلیز کا کوئی ترجمہ نہیں ہے، تو ناظرین انگریزی کی کوشش کرتا ہے۔ اگر آن لائن گائیڈ دستیاب نہیں ہے، تو دستیاب ہونے پر یہ مقامی کاپی دکھاتا ہے۔ سیدھا سیٹ اپ پر جانے کے لیے پہلے سیٹنگز کھولیں۔ کلک کریں۔ **پرنٹ کریں** موجودہ گائیڈ کو اس کے عنوان، پرنٹ کی تاریخ اور وقت، انسٹال شدہ ورژن، پروجیکٹ کا پتہ اور صفحہ نمبر کے ساتھ پرنٹ کرنے کے لیے۔

ناظرین کی ضرورت ہے۔ [مائیکروسافٹ ایج WebView2 رن ٹائم](https://developer.microsoft.com/microsoft-edge/webview2/). آپ بھی کھول سکتے ہیں۔ **کیمرہ کنٹرول اسٹوڈیو یوزر گائیڈز** انسٹال کرنے کے بعد اسٹارٹ مینو سے۔ پورٹیبل ورژن کے لیے، کھولیں۔ `docs` نکالے گئے فولڈر میں ZIP.
