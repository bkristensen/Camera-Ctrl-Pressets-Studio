# انٹرفیس اور ترجمے میں ترمیم کریں۔

* Camera Control Studio 1.0.1.* کے لیے لکھا گیا

## دائیں فائل کو کھولیں۔

`Camera-Control-Pressets-Studio.sln` کھولیں۔ حل ایکسپلورر میں، حل بنائیں، پھر `CameraControlStudio → Forms → MainForm.cs` کھولیں۔ **Shift+F7** Windows Forms Designer کے لیے دبائیں۔ `MainForm.Designer.cs` کو ڈیزائن کی سطح کے طور پر منتخب نہ کریں۔ کوڈ پر واپس جانے کے لیے F7 استعمال کریں۔

`.vsconfig` سے Visual Studio .NET ڈیسک ٹاپ ورک لوڈ انسٹال کریں۔ ایپلیکیشن .NET فریم ورک 4.8 پر WinForms ہے۔ WPF ڈیزائنر استعمال نہیں کیا جاتا ہے۔

## لے آؤٹ تبدیل کریں۔

`Dock`، `Margin`، `Padding`، قطار کے سائز اور کالم کے سائز کو تبدیل کرنے کے لیے پراپرٹیز پینل کا استعمال کریں۔ نیسٹڈ پینلز کو منتخب کرنے کے لیے دستاویز کی آؤٹ لائن کا استعمال کریں۔ مرکزی ترتیب میں میزیں اور `SplitContainer` کا استعمال کیا گیا ہے۔ ہارڈ کوڈڈ اسکرین کوآرڈینیٹ سے بچیں۔

ہر ونڈو `AppForm` سے وراثت میں ملتی ہے اور اس میں پیرامیٹر کے بغیر پبلک کنسٹرکٹر ہوتا ہے۔ لے آؤٹ کو `.Designer.cs` اور واقعات کو مماثل `.cs` فائل میں رکھیں۔ فارم کی `Icon` پراپرٹی کو ڈیزائنر میں سیٹ کریں۔ Visual Studio اور چل رہی ایپ میں لے آؤٹ چیک کریں۔

کیمرہ وہیل اور نیلے بٹن `Controls/BlueControls.cs` میں بنائے گئے ہیں۔ عمودی ڈیوائیڈر اور زوم کنٹرولز `Controls/MainViewControls.cs` میں ہیں۔ ڈیزائنر ان کنٹرولز کو حرکت اور سائز دے سکتا ہے۔ پیش سیٹ آئیکن امیجز اور ان کے نیوٹرل ٹائٹلز `Assets/PressetIcons.resx` میں ہیں، اور `Controls/PresetIcons.cs` انہیں لوڈ کرتا ہے۔ ویڈیو ٹیب ڈیزائنر کے تصنیف کردہ سلائیڈرز پر مشتمل ہے۔ چلنے والی ایپ کیمرہ ڈرائیور کے ذریعہ سپورٹ کردہ سلائیڈرز دکھاتی ہے۔

## ڈیفالٹس سیٹ کریں۔

نئے پروفائل کی ترتیبات کے لیے `SavedData.Defaults` میں، `Shared/Models.cs` میں ترمیم کریں۔ ابتدائی ترتیب کے لیے `ProfileLayout` میں ترمیم کریں۔ موجودہ پروفائلز اپنی محفوظ کردہ اقدار کو برقرار رکھتے ہیں۔ نئے ڈیفالٹس کو جانچنے کے لیے ایک نیا پروفائل بنائیں؛ صارف کے پروفائلز کو مجبور کرنے کے لیے حذف نہ کریں۔

## ترجمہ کو اپ ڈیٹ کریں۔

`Shared/Locales` کے تحت متعلقہ زبان کی فائل میں مماثل قدر میں ترمیم کریں۔ `key` کو غیر تبدیل شدہ رکھیں۔ XML کو ایک ایمپرسینڈ کے لیے `&amp;` کی ضرورت ہے۔ تمام فائلوں میں ایک جیسی چابیاں ہونی چاہئیں۔ ذخیرہ شدہ کیمرہ اور آئیکن آئی ڈیز کو بغیر تبدیلی کے رکھیں۔

`scripts/check-translations.ps1` چلائیں، پھر تعمیر کریں۔ `"Camera Control Studio.exe" --lang=de` یا سیٹنگز میں لینگویج سلیکٹر کے ساتھ ٹیسٹ کریں۔ محفوظ کردہ زبان کے انتخاب کو تبدیل کرنے کے بعد دوبارہ شروع کریں۔

## ایک زبان شامل کریں۔

`en.xml` کو ایک نئی لینگویج کوڈ فائل میں کاپی کریں۔ ہر قیمت کا ترجمہ کریں اور کوڈ اور نام کو `Shared/UiText.cs` میں رجسٹر کریں۔ ترجمہ چیکر اور لوکیل ٹیسٹ خود بخود نئی فائل اور رجسٹریشن کو اٹھا لیتے ہیں۔ MSIX مینی فیسٹ میں ایپ کی زبان کا اعلان کریں۔

خودکار انتخاب ونڈوز لینگویج کا سابقہ استعمال کرتا ہے۔ غیر تعاون یافتہ زبانیں واپس انگریزی میں آتی ہیں۔ تنگ کھڑکیوں اور لمبے لیبلوں کی جانچ کریں۔ ترجمہ کنٹرولز کو نہیں چھپانا چاہیے۔
