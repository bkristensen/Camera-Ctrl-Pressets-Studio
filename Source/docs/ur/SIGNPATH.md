# کوڈ پر دستخط کرنے کی پالیسی

SignPath فاؤنڈیشن اہل اوپن سورس پروجیکٹس کے لیے مفت دستخط کی پیشکش کرتی ہے۔ قبولیت کی ضرورت ہے۔ سرٹیفکیٹ SignPath فاؤنڈیشن کی بطور پبلشر شناخت کرتا ہے۔ سروس لنکس کی تصدیق شدہ تعمیرات سورس ریپوزٹری سے ہوتی ہیں۔ پروجیکٹ نے SignPath فاؤنڈیشن پر دستخط کے لیے درخواست دی ہے۔ درخواست زیر التواء ہے، اور GitHub ڈاؤن لوڈز غیر دستخط شدہ ہیں۔

درخواست دینے سے پہلے، ذریعہ کو اس کے لائسنس کے تحت شائع کریں۔ پروجیکٹ کو موجودہ رکھیں۔ ایک ریلیز شائع کریں، ایپ کو دستاویز کریں اور تعمیر کو قابل تصدیق بنائیں۔ صرف اپنی پراجیکٹ فائلوں پر دستخط کریں۔ مخزن سے باہر اسناد پر دستخط کرتے رہیں۔

[ رازداری کی پالیسی](../../PRIVACY.md) ایپ، اس کے GitHub اپ ڈیٹ چیک اور GuideViewer کے WebView2 رن ٹائم کا احاطہ کرتی ہے۔

## جبکہ درخواست زیر التوا ہے۔

- چیک کریں کہ عوامی ذخیرے میں **Actions** کے تحت کامیاب ونڈوز کی تعمیر ہے۔ اس ورک فلو کو SignPath انضمام کی بنیاد کے طور پر استعمال کریں۔
- عہدوں، جائزوں اور منظوریوں پر دستخط کرنے کے ذمہ دار لوگوں کی تصدیق کریں۔ GitHub اور SignPath پر ٹیم کے تمام اراکین کے لیے ملٹی فیکٹر تصدیق کو آن کریں۔
- SignPath سے پوچھیں کہ WebView2 SDK بائنریز اور Inno Setup انسٹالر کو کیسے ہینڈل کیا جانا چاہیے۔ پیکیجز میں Microsoft کی SDK بائنریز اور لوڈرز شامل ہیں۔ ایپ صارف کے پی سی پر نصب WebView2 رن ٹائم کا استعمال کرتی ہے۔ درخواست میں ان انحصاروں کی فہرست بنائیں اور ان کے نوٹس کو محفوظ رکھیں۔
- شامل کریں **کوڈ پر دستخط کرنے کی پالیسی** سے لنک GitHub ایپلی کیشن میں فراہم کردہ ڈاؤن لوڈ پیج کے لیے نوٹس جاری کریں۔ ان ڈاؤن لوڈز کی اصل دستخط کی حیثیت بیان کریں۔

## SignPath کے پروجیکٹ کو قبول کرنے کے بعد

- اس صفحہ پر منظور شدہ SignPath انتساب اور کمٹٹرز، جائزہ لینے والوں اور منظوری دینے والوں کے لیے تصدیق شدہ نام یا اجازت گروپ شامل کریں۔
- SignPath کو قابل اعتماد GitHub Actions بلڈ سے نمونے قبول کرنے کے لیے کنفیگر کریں۔ پراجیکٹ بائنریز پر دستخط کرنے کو محدود کریں۔ ایک ساتھ جمع کرائی گئی فائلوں میں پروڈکٹ کا نام اور مماثل پروڈکٹ ورژن سیٹ اور نافذ کریں۔
- ZIP کے لیے، پیکیجنگ سے پہلے قابل عمل ایپ پر دستخط کریں۔ انسٹالر کے لیے، تیار شدہ انسٹالر پر دستخط کرنے سے پہلے دستخط شدہ ایپ کو انسٹالر میں ایگزیکیوٹیبل رکھیں۔ ہر ریلیز پر دستخط کرنے کی درخواست کے لیے دستی منظوری حاصل کریں۔
- مستند دستخطوں اور ٹائم اسٹیمپ کی تصدیق کریں، پھر SHA-256 چیکسم بنائیں۔ جاری نوٹ میں **Code پر دستخط کرنے کی پالیسی** لنک اور دستخط کی حیثیت شامل کریں۔ شائع کرنے سے پہلے اپ لوڈ کردہ فائلوں اور ہیشز کی تصدیق کریں۔

براہ راست GitHub ڈاؤن لوڈز کے لیے، ایک درست دستخط ناشر کی شناخت کرتا ہے اور بائنری کی سالمیت کی حفاظت کرتا ہے۔ ایک نیا ڈاؤن لوڈ اب بھی SmartScreen کو متحرک کر سکتا ہے جب کہ ساکھ بنتی ہے۔ اسٹور کے ذریعے پہلی بار تقسیم کرنے کے لیے، مائیکروسافٹ نے MSIX پیکیجز کو قبول کیا۔

موجودہ صارف کے ونڈوز سرٹیفکیٹ اسٹور کے ذریعے دستیاب عوامی طور پر قابل اعتماد کوڈ پر دستخط کرنے والے سرٹیفکیٹ کے لیے، پورٹیبل ZIP کے لیے `scripts/build.ps1 -CertificateThumbprint <thumbprint> -SignToolPath <path>` استعمال کریں۔ ایک ہی پیرامیٹرز کو `scripts/build-installer.ps1` کے ساتھ استعمال کریں تاکہ قابل عمل ایپ اور جنریٹڈ انسٹالر دونوں پر دستخط کریں۔ SignPath منظوری کے لیے اس کے اپنے دستخطی ورک فلو کی ضرورت ہوتی ہے۔
