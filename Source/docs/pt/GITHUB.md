# Camera Control Studio em GitHub

*Escrito para Camera Control Studio 1.0.1.*

Abra o projeto [ no GitHub](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio) para ler códigos, guias, lançamentos e relatórios públicos. Faça login para postar ou propor uma alteração.

<https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio>

| Área | Use-o para |
| --- | --- |
| Código | Navegue pela fonte, README e instruções de contribuição. |
| Lançamentos | Baixe um instalador publicado ou portátil ZIP de **Assets** e leia as notas de versão. |
| Problemas | Pesquise, relate e siga bugs ou solicitações de recursos concretos. Consulte o relatório [ ou siga um problema ](ISSUES.md). |
| Discussões | Faça perguntas sobre uso ou discuta ideias que ainda estão tomando forma. |
| Solicitações pull | Revise as alterações propostas e acompanhe a discussão e as verificações. |

## Proponha uma mudança

1. Leia [Contributing](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/blob/main/Source/CONTRIBUTING.md) e procure um problema relacionado ou solicitação pull.
2. Bifurque o repositório se você não tiver acesso de gravação. Crie uma ramificação a partir da ramificação `main` do projeto.
3. Faça uma mudança específica, verifique-a e confirme-a com uma breve descrição. Empurre o galho para o garfo.
4. Na guia **Pull requests** do projeto, abra uma solicitação pull direcionada a `main`. Explique o que mudou, como você testou e vincule qualquer problema relacionado.
5. Siga as verificações e revise. Envie as correções para o mesmo branch para que apareçam na solicitação pull existente.

Para alterações de tradução, consulte [Traduzir o aplicativo](TRANSLATIONS.md).
