# Denunciar ou acompanhar um problema

*Escrito para Camera Control Studio 1.1.1.*

[Solução de problemas](TROUBLESHOOTING.md)

## Pesquise antes de denunciar

**Relate um bug ou sugira um recurso**\
<https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/issues?q=is%3Aissue>\
Código ![QR para os problemas GitHub do projeto](../images/qr/issues.png)

1. Abra a guia Problemas [ do projeto](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/issues?q=is%3Aissue). Pesquise termos-chave do sintoma ou solicitação, como `is:issue Brio zoom` ou `is:issue label:enhancement preset`.
2. Verifique os resultados abertos e fechados. Leia relatórios semelhantes para encontrar sintomas e soluções alternativas.
3. Em um problema correspondente, selecione **Subscribe** na barra lateral para receber atualizações ou reaja com 👍 para mostrar que isso afeta você. Adicione um comentário se puder contribuir com detalhes como uma câmera diferente, um resultado de teste ou uma reprodução confiável.

![Pesquisa de problemas acima das guias Aberto e Fechado. O novo problema está no canto superior direito.](../images/reporting/github-issues.png)

## Abra um relatório

Abra o painel de configurações. Selecione **Contato e sobre → Contato**. Selecione **Relatar um problema** ou **Solicitar um novo recurso** para abrir o rascunho correto no GitHub. Para problemas, o aplicativo oferece salvar um ZIP de suporte. Revise o arquivo e anexe-o ao rascunho. [Relatar um problema](Report%20a%20bug.md) · [Solicitar um novo recurso](Request%20a%20feature.md)

Para um bug, inclua a versão Camera Control Studio, versão do Windows, modelo da câmera, câmera relevante ou software de captura e a ordem em que você iniciou os aplicativos. Descreva as etapas exatas, o que você esperava, o que aconteceu e com que frequência. Para uma solicitação, descreva a tarefa que você deseja realizar e como usaria o recurso.

![Editor de problemas do GitHub com título, descrição, upload de arquivo e botão Criar](../images/reporting/github-new-issue.png)

Se **Type** estiver disponível, use **Bug** para comportamento inesperado, **Feature** para uma solicitação ou **Task** para um trabalho definido. Se você puder aplicar rótulos, use os mais relevantes, como `bug`, `enhancement`, `documentation` ou `accessibility`. Os mantenedores podem adicionar metadados após o envio.

## Anexar evidências

Selecione **Contato e sobre → Contato → Salvar ZIP de suporte** e escolha onde salvar o pacote. O aplicativo mostra o caminho do arquivo.

O ZIP inclui uma captura do aplicativo, o arquivo salvo `profiles.json`, o layout da janela em `window.json` e os registros disponíveis em `Logs`.

Revise o ZIP para retirar dados privados, como nomes de perfis, IDs de câmeras e caminhos de arquivos. Arraste você mesmo o ZIP ou os arquivos úteis para a descrição do rascunho.

Confira a descrição e os anexos em **Preview** e escolha **Create**.
