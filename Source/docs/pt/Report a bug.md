# Relatar um problema

1. Abra o painel de configurações. Selecione **Contato e sobre → Contato → Relatar um problema**.
2. Se houver uma versão mais recente, escolha **Sim** para abrir a página de download. Instale-a e verifique se o problema ainda ocorre. Escolha **Não** para continuar no rascunho do GitHub.
3. Se o aplicativo oferecer um ZIP de suporte, escolha **Sim** e selecione onde salvá-lo. Escolha **Não** para abrir o rascunho sem criar o arquivo.

![Aba de contato com os botões do GitHub e do ZIP de suporte](../images/screenshots/contact/pt/issues.png)

## Adicione detalhes e anexe o ZIP

O botão abre o modelo **Bug report** do GitHub. Conte o que esperava, o que ocorreu e como reproduzir o problema. Informe as versões do aplicativo e do Windows. Inclua a câmera e o programa de captura, se forem relevantes. Preencha todas as seções marcadas com um asterisco vermelho.

Selecione **Contato e sobre → Contato → Salvar ZIP de suporte** e escolha onde salvar o pacote. O aplicativo mostra o caminho do arquivo.

O ZIP inclui uma captura do aplicativo, o arquivo salvo `profiles.json`, o layout da janela em `window.json` e os registros disponíveis em `Logs`.

Revise o ZIP para retirar dados privados, como nomes de perfis, IDs de câmeras e caminhos de arquivos. Arraste você mesmo o ZIP ou os arquivos úteis para a descrição do rascunho.

![Rascunho no GitHub com descrição, área de anexos e botão Create](../images/reporting/github-new-issue.png)

## Confira o tipo e os rótulos

O modelo solicita **Bug** em **Type** e `bug` em **Labels**. Se faltarem e os campos estiverem disponíveis, selecione os valores na barra lateral direita. Se não puder editar os campos, envie o rascunho. Alguém da equipe do projeto poderá preenchê-los.

![Menu Type do GitHub com Bug, Task e Feature](../images/reporting/github-issue-type.png)

![Menu Labels do GitHub](../images/reporting/github-issue-labels.png)

Confira a descrição e os anexos em **Preview** e escolha **Create**.
