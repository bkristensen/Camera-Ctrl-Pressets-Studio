# 报告问题

*为Camera Control Studio 1.1.0.*编写

1. 点击底部的齿轮按钮打开设置。 选择 **联系与关于 → 联系 → 报告问题**。
2. 如果有更新版本，请选**是**打开下载页面。安装后，检查问题能否重现。选择**否**可继续打开 GitHub 草稿。
3. 应用询问是否保存支持 ZIP 时，选择**是**并指定保存位置。选择**否**可直接打开草稿。

指南查看器也提供相同的 GitHub 按钮。

![联系选项卡上的 GitHub 按钮和支持 ZIP 按钮](../images/screenshots/1.1.0/zh/issues.png)

## 补充详情并附上 ZIP

按钮会打开 GitHub 的 **Bug report** 模板。写明预期结果、实际结果和重现步骤。填写应用和 Windows 版本。如果相关，请补充摄像头和采集应用。 填写所有带红色星号的部分。

选择 **联系与关于 → 联系 → 保存支持 ZIP**，然后指定保存位置。应用会显示文件路径。

ZIP 包含应用截图、已保存的 `profiles.json`、记录窗口布局的 `window.json` 和 `Logs` 中可用的日志。

分享前请检查 ZIP，去掉配置名称、摄像头 ID 和文件路径等隐私信息。将 ZIP 或相关文件拖入草稿描述区。附件需要手动添加。

![含描述、附件区和 Create 按钮的 GitHub 草稿](../images/reporting/github-new-issue.png)

## 检查类型和标签

模板请求将 **Type** 设为 **Bug**，将 **Labels** 设为 `bug`。如果缺少这些值且可编辑，请在右侧栏选择。没有编辑权限时，可以先提交草稿，维护者可稍后补充。

![GitHub 的 Type 菜单，含 Bug、Task 和 Feature](../images/reporting/github-issue-type.png)

![GitHub 的 Labels 菜单](../images/reporting/github-issue-labels.png)

在 **Preview** 中检查说明和附件，然后选择 **Create**。
