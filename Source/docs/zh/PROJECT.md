# 项目描述

Camera Control Studio 在 Windows 上保存和调用相机拍摄的照片。在工作室、教室或现场会议中使用它。您的捕获应用程序处理视频。

## 核心行为

使用内环进行正常移动，使用外环进行快速移动。每个环都有对角箭头。双击中心按钮选择摄像机，或拖动它进行转向。您可以在“设置”→“平移”下更改这两种手势。变焦按钮按设定的步长移动。滑块设置当前 FOV 内的缩放。该应用程序不打开视频预览。 [设置运动和FOV](SETUP.md#%E8%AE%BE%E7%BD%AE%E8%A7%86%E9%87%8E)

永久位置存储名称、稳定符号 ID 以及驱动程序报告的平移、倾斜、变焦和 FOV。组合符号从左到右显示主题。永久职位首先以粗体显示。临时职位没有图标，直到您关闭应用程序为止。使用播放或双击来调用任一类型。

平滑插值需要中间坐标。过渡期间一行呈黄色。仅当回读与目标匹配时，它才呈绿色。手动操作、取消或失败的转换会清除该状态。驱动程序确定实际的运动粒度和延迟。

配置文件包含摄像机选择、永久位置、图像值、手动移动速率、预设转换持续时间或速度、方向反转、摄像机确认、窗口布局和语言。更改配置文件会使用所选配置文件的语言重新启动应用程序。可选的摄像头确认会阻止枚举和连接，直到用户确认流式传输已开始。

## 建筑

`CameraControlStudio` 是一个 .NET Framework 4.8 WinForms 应用程序。 `Forms/*.Designer.cs` 持有布局。 `Forms/*.cs`保持事件处理。 `AppForm`为公共底座。 `Controls` 包含矢量渲染。 `Camera.cs` 使用 Windows DirectShow 摄像头和视频处理接口，没有捕获图。

`Shared` 保存模型、持久性、翻译、运动算术、会话位置和状态逻辑。 `Tests` 是一个 .NET 8 控制台回归套件。配置文件使用原子文件替换、备份和修订检查。保留现有0.6配置文件存储；过时的程序启动设置将在保存时被忽略并丢弃。

## 范围和兼容性

业主报告说，早期的应用程序可以在他们的笔记本电脑和相机设置上运行。此 0.7 重写已编译并通过逻辑测试，但尚未在此构建环境中针对物理硬件进行测试。没有声称测试过任何额外的相机或捕获软件。

当其他 Windows 相机的驱动程序实现所需的标准控件时，它们可能会工作。捕获、会议或流媒体软件的并发访问取决于驱动程序。虚拟摄像机可能不会暴露任何物理控件。这不是通用网络 PTZ 控制器。 Linux 和 macOS 可以通过 Docker 工作流程构建主机，但无法本机运行此 Windows UI。

请报告成功的组合，包括 Windows 版本、相机型号、驱动程序版本、捕捉应用程序以及哪些控件有效。还报告限制，以便兼容性列表可以是基于证据的。
