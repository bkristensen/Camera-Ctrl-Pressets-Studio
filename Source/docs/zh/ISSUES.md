# 报告或关注问题

*为Camera Control Studio 1.1.0.*编写

[故障排除](TROUBLESHOOTING.md)

## 举报前搜索

**报告错误或建议功能**\
<https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/issues?q=is%3Aissue>\
![项目二维码 GitHub 问题](../images/qr/issues.png)

1. 打开项目的 [Issues 选项卡 ](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/issues?q=is%3Aissue)。从症状或请求中搜索关键术语，例如 `is:issue Brio zoom` 或 `is:issue label:enhancement preset`。
2. 检查打开和关闭的结果。阅读类似的报告以了解匹配的症状和解决方法。
3. 对于匹配的问题，请在侧边栏中选择 **Subscribe** 来接收更新，或通过 👍 做出反应以表明它对您有影响。如果您可以提供不同相机、测试结果或可靠再现等详细信息，请添加评论。

![在“打开”和“关闭”选项卡上方发出搜索。新问题在右上角。](../images/reporting/github-issues.png)

## 打开报告

打开设置面板。选择 **联系与关于 → 联系**。 选择 **报告问题** 或 **请求新功能** 打开对应的 GitHub 草稿。报告问题时，应用会询问是否保存支持 ZIP。请检查内容，并手动附到草稿中。 [报告问题](Report%20a%20bug.md) · [请求新功能](Request%20a%20feature.md)

对于错误，请包括 Camera Control Studio 版本、Windows 版本、相机型号、相关相机或捕获软件以及启动应用程序的顺序。描述确切的步骤、您的期望、发生的情况以及频率。对于请求，请描述您想要完成的任务以及如何使用该功能。

![GitHub问题编辑器，带有标题、描述、文件上传和创建按钮](../images/reporting/github-new-issue.png)

如果 **Type** 可用，则使用 **Bug** 表示意外行为，使用 **Feature** 表示请求，或使用 **Task** 表示定义的工作。如果您可以应用标签，请使用最相关的标签，例如 `bug`、`enhancement`、`documentation` 或 `accessibility`。维护者可以在提交后添加元数据。

![GitHub 问题类型菜单，包含任务、Bug 和功能](../images/reporting/github-issue-type.png)

## 附上证据

选择 **联系与关于 → 联系 → 保存支持 ZIP**，然后指定保存位置。应用会显示文件路径。

ZIP 包含应用截图、已保存的 `profiles.json`、记录窗口布局的 `window.json` 和 `Logs` 中可用的日志。

分享前请检查 ZIP，去掉配置名称、摄像头 ID 和文件路径等隐私信息。将 ZIP 或相关文件拖入草稿描述区。附件需要手动添加。

在 **Preview** 中检查说明和附件，然后选择 **Create**。
