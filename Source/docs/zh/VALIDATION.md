# 0.7.0-beta.3 的验证

*为Camera Control Studio 1.1.0.*编写

Windows 发行版本使用锁定的依赖项。翻译奇偶校验和自动化测试均已通过。测试涵盖运动、预设、配置文件语言、持久性、日志记录以及休眠后报告的相机未就绪 HRESULT。

提取的便携式 ZIP 在 x86 和 x64 Windows 进程中进行了测试。两者都打开并重新打开日常使用和设置指南，显示屏幕截图并打印到 PDF。 x64 PDF 在所有五个页面上都有标题、版本、日期和正确的页数。 **?** 按钮在 WinForms 设计时初始化期间出现。检查 ARM64 加载程序的二进制架构是否正确。

英语标准轮廓是用演示相机拍摄的。 12 个全窗口屏幕截图涵盖了主窗口状态、每个设置选项卡和每个子选项卡。指南和自述文件中的本地链接已根据打包文档路径进行检查。

## Brio 视野和变焦

使用提供 65°、78° 和 90° 的物理 Brio。请注意型号、固件、驱动程序、应用程序版本以及 Zoom 使用的视频模式。

1. 启动“缩放”并使用边缘附近具有可见参考点的固定场景。使用 Logitech Brio Control 确认 90° 的最宽取景和最小变焦。
2. 使用 **保持不变** 启动 Camera Control Studio 并确认设备保留其 FOV。使用 **最宽可用视野** 重新启动，然后使用指定的 FOV 重复并启用流确认。
3. 在所有三个应用程序运行的情况下，在 Logitech Brio Control 中更改平移、倾斜、变焦和 FOV。在手动 FOV 禁用和启用的情况下确认 Camera Control Studio 中更新的读数。
4. 将 FOV 更改为 Camera Control Studio。观察 Logitech Brio Control 何时更新其自己的显示屏。保存和调用每个 FOV 的预设，包括不带 FOV 的旧预设。
5. 从狭窄的放大镜头中，选择 **完整画面** 并将图像与步骤 1 中的参考图像进行比较。在预设过渡期间并在 Logitech Brio Control 已打开的情况下重复此操作。
6. 关闭Camera Control Studio并检查Logitech Brio Control是否仍然可以更换摄像头。以相反的应用程序启动顺序重复此操作。附上诊断日志并记下实时图像与报告值之间的任何差异。
7. 在 65° 和最小变焦时，按缩小一次。检查 FOV 是否更改为 78°，下一步缩小。在 78° 处重复。检查缩小是否仅在 90° 和最小变焦处停止。测试放大的反向路径。
8. 在水平平移边缘，再次按相同的箭头。检查更宽的 FOV 和变焦调整是否允许在不丢失镜头的情况下进行运动。如果视图没有帮助，请检查原始帧是否返回。关闭该功能并确认 FOV 保持原状。

Inno Setup 7 编译了安装程序，其中包含所有 12 种语言以及 x86、x64 和 ARM64 加载程序的指南。两个包均未签名，并提供了 SHA-256 哈希值。干净帐户安装和卸载、物理相机休眠周期和 ARM64 运行时测试正在等待中。请参阅 [ 发布清单 ](RELEASE-CHECKLIST.md) 和 [ 构建和发布指南 ](BUILD-AND-RELEASE.md)。
