# 发布清单

*为Camera Control Studio 1.1.1.*编写

使用 [ 构建和发布指南 ](BUILD-AND-RELEASE.md) 来获取命令和输出路径。

## 自动检查

- [ ] 在具有锁定依赖项的干净结帐上运行 `scripts/build.ps1`。
- [ ] 确认每个区域设置都具有相同的唯一非空键。构建运行翻译检查和区域设置测试。
- [ ] 查看源代码和二进制版本、包标识和发行说明。

## 窗户和摄像头检查

- [ ] 以 900 × 500 启动并验证最小值 670 × 450。以 100%、125%、150% 和 200% 显示缩放比例调整大小、最大化和恢复。检查页脚、输入、组合图标和缩放字形。
- [ ] 打开右侧的设置。拖动分隔线。关闭并重新打开。断开显示器连接后测试保存的布局。
- [ ] 调用位置：移动期间为黄色，仅在匹配回读后才为绿色。平移/倾斜/缩放可清除活动颜色。转换期间断开连接：无假绿色。确认后图标永远不会消失。
- [ ] 测试每个组合图标，包括每个相反的顺序。测试缩放按钮、缩放滑块和两个方向反转。
- [ ] 在支持的 Brio 上，在两个缩放方向以及左右平移边缘测试自动 FOV。遵循 [Brio 测试步骤 ](VALIDATION.md#brio-%E8%A7%86%E9%87%8E%E5%92%8C%E5%8F%98%E7%84%A6)。
- [ ] 启用相机确认。重新启动。在“是”之前验证没有相机枚举或连接。测试否，然后通过平移/缩放按钮重试。测试配置文件更改和源选择。

## 数据和编辑

- [ ] 迁移前备份 0.6 配置文件。确认预设和图标 ID 仍然存在。确认保存后不存在过时的外部程序设置。
- [ ] 测试新/复制/重命名配置文件、恢复布局和保持当前布局行为。验证临时职位是否仅限会话。
- [ ] 使用实际相机测试图像自动/手动设置和默认设置。
- [ ] 在 Visual Studio 中使用 Shift+F7 打开每个表格。调整布局属性，保存并重建。自定义绘图保留在控件类中。
- [ ] 在 64 位 Windows 进程中从提取的 ZIP 打开指南查看器。再次打开它并打印 PDF 的指南。确认安装程序和 ZIP 在每个支持的架构的 `runtimes` 下包含匹配的 WebView2 本机加载程序。
- [ ] 检查 [ 用户指南索引 ](USER-GUIDES.md) 并确认两个包中都存在每种语言指南。检查 [ 指南屏幕截图 ](SCREENSHOTS.md) 以了解完整的选项卡和子选项卡覆盖、裁剪和重叠。

## 分布

- [ ] 对于便携式版本，请使用 `scripts/build.ps1`。对于 Inno Setup 安装程序，请使用 `scripts/build-installer.ps1`，它还运行便携式构建和测试。验证安装程序和应用程序显示的版本。
- [ ] 对于商店版本，请遵循 [ 商店清单 ](MSIX-AND-STORE.md)。测试您计划在 Windows 上发布的包类型。
- [ ] 如果进行签名，请验证应用程序可执行文件和安装程序（如果适用）上的 Authenticode 签名。清楚地标记未签名的下载。最终签名和打包后生成 SHA-256 哈希值。
- [ ] 链接到 [代码签名政策](SIGNPATH.md) 在 GitHub 发行说明。对于 SignPath 发布、验证构建来源以及手动批准和信用 SignPath 对于它签署的文件。
- [ ] 一起发布源代码、许可证、发行说明、哈希值和二进制文件。请勿声称未经执行的硬件测试或商店批准。
