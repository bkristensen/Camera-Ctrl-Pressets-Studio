## 提出改变

1. 阅读 [Contributing](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/blob/main/Source/CONTRIBUTING.md) 并查找相关问题或拉取请求。
2. 如果您缺乏写访问权限，则分叉存储库。从项目的 `main` 分支创建一个分支。
3. 进行有针对性的更改，验证它，并通过简短的描述提交它。将树枝推到叉子上。
4. 在项目的 **Pull requests** 选项卡中，打开针对 `main` 的拉取请求。解释发生了什么变化，如何测试它，并链接任何相关问题。
5. 遵循检查和审查。将更正推送到同一分支，以便它们出现在现有的拉取请求中。

有关翻译更改，请参阅 [ 翻译应用程序](TRANSLATIONS.md)。
