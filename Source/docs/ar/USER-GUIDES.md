# أدلة المستخدم Camera Control Studio

* مكتوب لـ Camera Control Studio 1.1.0.*

يشتمل برنامج التثبيت وجهاز ZIP المحمول على الأدلة. انقر فوق **?** لفتح الأدلة المحلية بلغة ملفك الشخصي. قم بتغيير **لغة الدليل** لقراءة ترجمة مختلفة. اختر **استخدام الأدلة عبر الإنترنت** لقراءة الدليل من أحدث إصدار من GitHub. إذا لم يكن لهذا الإصدار ترجمة، فسيحاول المشاهد استخدام اللغة الإنجليزية. إذا لم يكن الدليل عبر الإنترنت متاحًا، فسيتم عرض النسخة المحلية عند توفره. افتح الإعدادات أولاً للانتقال مباشرة إلى الإعداد. انقر فوق **طباعة** لطباعة الدليل الحالي بعنوانه وتاريخ ووقت الطباعة والإصدار المثبت وعنوان المشروع وأرقام الصفحات.

عندما يكون Microsoft Store مصدر التحديثات، يبحث العارض عن الأدلة عبر الإنترنت للإصدار المثبّت.

يحتاج العارض إلى [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/). يمكنك أيضًا فتح دليل مستخدم **Camera Control Studio ** من القائمة "ابدأ" بعد التثبيت. بالنسبة للنسخة المحمولة، افتح المجلد `docs` في ملف ZIP المستخرج.

<https://developer.microsoft.com/microsoft-edge/webview2/>
