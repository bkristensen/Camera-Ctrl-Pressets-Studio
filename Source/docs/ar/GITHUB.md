# Camera Control Studio على GitHub

* مكتوب لـ Camera Control Studio 1.1.0.*

افتح مشروع [ على GitHub](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio) لقراءة التعليمات البرمجية والأدلة والإصدارات والتقارير العامة. قم بتسجيل الدخول لنشر أو اقتراح تغيير.

<https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio>

| المنطقة | استخدامه ل |
| --- | --- |
| الكود | تصفح المصدر، الملف التمهيدي وتعليمات المساهمة. |
| الإصدارات | قم بتنزيل برنامج التثبيت المنشور أو ZIP المحمول من **Assets** واقرأ ملاحظات الإصدار. |
| القضايا | البحث عن الأخطاء أو طلبات الميزات الملموسة والإبلاغ عنها ومتابعتها. راجع [الإبلاغ أو متابعة المشكلة](ISSUES.md). |
| المناقشات | اطرح أسئلة حول الاستخدام أو ناقش الأفكار التي لا تزال في طور التبلور. |
| سحب الطلبات | قم بمراجعة التغييرات المقترحة ومتابعة المناقشة والفحوصات. |

## اقتراح التغيير

1. اقرأ [Contributing](https://github.com/bkristensen/Camera-Ctrl-Pressets-Studio/blob/main/Source/CONTRIBUTING.md) وابحث عن مشكلة ذات صلة أو طلب سحب.
2. قم بتفرع المستودع إذا كنت تفتقر إلى إمكانية الوصول للكتابة. قم بإنشاء فرع من فرع `main` للمشروع.
3. قم بإجراء تغيير مركّز، وتحقق منه، والتزم به من خلال وصف قصير. ادفع الفرع إلى شوكتك.
4. في علامة التبويب طلبات **Pull** الخاصة بالمشروع، افتح طلب سحب يستهدف `main`. اشرح ما الذي تغير، وكيف قمت باختباره، واربط أي مشكلة ذات صلة.
5. اتبع الشيكات والمراجعة. ادفع التصحيحات إلى نفس الفرع حتى تظهر في طلب السحب الموجود.

لمعرفة تغييرات الترجمة، راجع [ترجمة التطبيق](TRANSLATIONS.md).
