# Quick start

1. Extract the portable ZIP, close old copies and run Cam Pressets Studio.exe.
2. In Settings, configure the startup-program paths and process names. Enable
   automatic startup if desired; otherwise start those applications yourself.
3. Start/join the Zoom meeting and verify the image. Leave the default camera
   startup gate enabled. Click “Zoom meeting is ready — enable camera” and confirm.
4. Select the camera, frame with the wheel/zoom, and save the current position
   under a meaningful name. Use the row play button to recall it.
5. Adjust steps and transition duration under Settings; save settings. Close the
   panel for everyday use. Escape stops movement.

Do not confirm meeting readiness merely because Zoom's main window is visible.
The app checks processes; you confirm the actual meeting. If the image flips,
stop, close Studio and re-establish the correct image in Zoom before reconnecting.

Back up your profiles before upgrades. Presets are camera-specific: selecting a
different camera may show a different or empty list. See FAQ for non-Zoom use.
