# SignPath for open-source distribution

SignPath Foundation offers free signing to eligible open-source projects, subject
to review. It is not automatic approval or a certificate owned by the maintainer.
It can support direct downloads outside the Store; it does not publish the app.

## Application checklist

- [ ] Publish and maintain a documented open-source project with an eligible license.
- [ ] Establish a verifiable source-to-release build and project reputation.
- [ ] Review current eligibility, security, attribution and artifact requirements.
- [ ] Enable MFA and assign reviewer and signing-approval responsibilities.
- [ ] Provide a privacy policy and installation/uninstallation instructions.
- [ ] Apply; configure signing only after acceptance.
- [ ] Document actual approval status and manually approve each signing release.

Current status: **not applied, not approved, not signed by SignPath**. Do not add
provider endorsements or badges as though approval has already occurred.
See [Code signing policy](../CODE-SIGNING-POLICY.md) for the project's current policy.

Signing establishes artifact provenance; it does not guarantee bug-free software
or immediate absence of Windows reputation warnings. The existing certificate-store
script is not a SignPath integration. Provider integration remains future work.
