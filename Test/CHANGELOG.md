# Changelog

## 0.6.4-beta.1

- Optional, streaming-app-independent confirmation at first camera use; default off for new profiles. Existing choices are preserved.
- Camera actions connect on demand; center camera symbol opens source selection.
- Settings accessible through the gear; redundant profile-row settings button removed.
- Expanded driver-supported image controls and image-only driver default reset.
- Localized UI title: Camera Control & Pressets. Executable and storage names remain compatible.
- Factory defaults centralized in SavedData.InitializeDefaults; guides explain defaults.

## 0.6.3-beta.1

- Thirty scalable preset symbols, saved per preset and editable with the pencil button.
- Double-click a preset name to recall; play and Enter remain available.
- Resize redraw for custom controls; rounded button background cleanup.
- Two-row profile toolbar and reduced zoom padding for narrow windows.
- Developer bootstrap, SDK/workload configuration and locked NuGet dependencies.
- UI development guides in English, Danish and German.
- Windows visual/hardware verification of this version remains pending.

## 0.6.2-beta.1
- Added German UI resources and per-user language selection with restart.
- Added English, Danish and German daily-use, setup and translation guides.
- Added translation-key validation and language fallback tests.

## Unreleased
- Added an unsigned MSIX packaging path with explicit Store identity parameters.
- Added Store, SignPath, compatibility, licensing and release documentation.
- Added GitHub feature/compatibility forms and contribution guidance.
- Added Docker build/export scripts; Docker execution remains unverified here.

## 0.6.1-beta.1
- Camera startup gate enabled for new and older profiles by default.
- Required-program/Zoom process checks and explicit meeting-readiness confirmation.
- Camera enumeration/connection blocked until permission is granted.

## 0.6.0-beta.1
- Consolidated distribution into one Studio app with blue dual-ring camera controls.
- Collapsible settings, per-profile movement settings and camera selection.
- Retained shared profiles, legacy import, ordered startup and optional settings code.

These entries describe implemented changes, not full Windows/hardware certification.
